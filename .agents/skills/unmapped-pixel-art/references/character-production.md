# 角色资产与动作试制

用于同一角色的多方向站姿、负重行走、转身和作业动作。场景插画或单张人物图不必套用整套流程。

## 先判断输入能承担什么

区分身份／风格参照、动作参照与可制作资产。认可一张原画，只能确认其中已表现的造型；不能据此认定视频中的其他朝向、隐藏身体部位或推算的侧面也已成立。

转身视频的中间帧可能有变化的脸型、衣装、光照和腿脚结构。能读出朝向，不代表它适合拆层、绑定或充当稳定站姿。保留来源并核对完整人体，不把帧号正确与造型正确混为一谈。

先看完整角色在目标显示尺寸上的轮廓和接触，再放大检查像素。局部有问题时，同时查看相邻的结构：头部连同颈肩和衣领，裤腿连同髋膝踝与鞋，手连同器物和承重肩。反复缩放一块图像容易把问题移到接缝。

## 建立同一角色的制作基准

按本次角色记录必要的比例与结构：头顶—颈根、肩线、髋部、膝踝、鞋底和握点，以及服装开口、衣摆、装备所属肢体与光源。比例来自当前设计，不强制所有角色为某一头身比。

统一相机俯角、透视／正交关系与身体尺度。角色可见身高、根节点、足底与画布边距分别记录；相同 PNG 高度或相同裁切框高度不代表人体比例已对齐。器物伸出和透明留白不能充当身体的缩放基准。

先自行并排检查完整站姿。若脸型、肩宽、衣领、膝踝和器物仍不能读成同一角色，优先修整个相关结构或重新选择源资产，不扩成更多方向和动作。只有缺失信息会实质影响设计时再询问用户。

通用人体与材质不能自动保留原画的服装设计。肩部观感同时取决于颈根、衣领、肩峰、袖笼与负重；只降低肩关节可能从耸肩变为垮肩。对照完整轮廓与服装结构后，再判断需要改骨架、源衣装还是光照，避免反复升降同一参数。

## 用小样验证方法，不由工具名称推断结果

| 制作方法 | 需要先具备 | 小样要验证什么 |
| --- | --- | --- |
| 二维拆件／网格／骨骼 | 合格角色画、可补足的隐藏区域、明确遮挡与握点 | 关节与衣物能否连续，像素轮廓是否抖动，装备是否随受力 |
| 完整逐帧绘制或精修 | 稳定角色设计、完整关键姿态和实际绘制能力 | 跨帧比例、体积、材质、接触与色块是否连续 |
| 三维角色离线预渲染 | 可编辑且来源可用的角色模型、骨架、衣装与装备 | 同一模型能否保持身份与方向，固定相机／光源能否接近目标像素画风 |
| 生成图片／视频 | 明确参照作用、可用的控制方式与本批预算 | 是否真的服从方向、身份、器物与像素尺度，而非只生成了看似精美的图 |

方法可以组合。三维轮廓一致不等于自动得到绘画式光色；二维骨骼可运行不等于适合任意原画。原画纹理取样、程序轮廓和调色是制作辅助手段，不能默认替代完整人体与衣服的绘制。

使用真实动作记录时，先核对记录内容、帧率、坐标与骨架，再检查同一段完整人体运动。非负重行走的时序可以提供参照，但减小手臂摆幅并不等于获得了真实负重动作。按目标人体比例转移后，重新检查接地、遮挡、握持与装备；参考模型的身份和材质不自动成为成品美术。连续行走资料若没有起停与转身，不凭空把这些动作标成已交付。

动作转移先建立无附加修正的基准，将源骨架、目标骨架和实际蒙皮同步对照。近乎伸直的关节不能仅靠三个关节点推断弯曲平面；保留来源的解剖关节轴、静止姿态与骨骼方向，检查有符号屈伸及相邻帧连续性。目标骨架将一个肢段拆成多个变形骨时，共享该肢段的刚性变换并保留各骨静止偏移，避免各段独立瞄准同一方向而改变轮廓或扭转。

手部另核对掌轴、拇指侧、前臂旋转与手指静止姿态。来源骨架的 hand／thumb 辅助点不自动等于目标模型的掌面标定；整体重置骨架还可能把手指恢复成张开的默认姿态。用实际指根几何建立目标掌向，检查袖口—手腕—掌指的完整关系，不能只比较肩肘腕三个点。缺少已验证的手部捕捉时可明确制作放松手姿，保留可信的前臂转动，标明改编范围；没有依据时不要把摊开的手或不自然的持续腕偏折当作可交付细节。

手持器物的“朝向目标”还不足以验证使用姿态。检查携带与使用是否需要换握，以及手掌、拇指和器物正反面的关系；具体见[持物与查看](editable-character-pipeline.md#持物与查看)。

坐标校准、接地修正和负重改编分别加入、分别记录对源动作的改变。整段共用的地面旋转／平移与逐帧移动骨盆有不同含义；需要接触补偿时同时对照原始屈伸曲线和全身姿态，无法兼容就明确保留残差。脚点误差、假设质量的质心曲线或工程重现通过，均不能证明解剖方向、承重或动作自然；判定模型时检查保存重开后实际求值的几何，不能只读求解器报告。

复用拟合衣装时一起检查网格、源蒙皮、身体遮挡、UV 和透明度。鞋面穿出肤色可能来自漏读身体遮挡范围，不能只用调色盖掉；资产提供专用权重时，先核对有效骨名和顶点覆盖，再考虑重新推算。用连通部件着色和结构近景辨认翻领、内衫或鞋面，比凭材质名猜测更可靠；这些诊断图不替代目标像素尺寸的验收。

共享材质时区分真正共享的部分。带透明纹理的头发材质若复用于没有对应 UV 的眉毛或其他部件，可能把它们错误隐藏。眉眼等小特征同时看结构和原生显示尺寸：高分辨率下存在的细线，经过采样与色阶归并后仍可能不可辨，不应靠独立放大整个头部解决。

先用一个方向的完整站姿，以及必要的少量关键姿态测试制作链。姿态数量按需要决定，避免用大量中间帧掩盖基本形体问题。动作自然度、素材一致性成立后再增加循环帧、其他方向或网页交互。

需要持续补绘、修改绑定并重新导出时，阅读[可回改的人物制作管线](editable-character-pipeline.md)：先复现完整制作片段，再区分共享母版、骨架与姿态修绘，验证修改能经过整条流程进入输出。

## 像素变换的限制

最近邻只是取样方式。小角度旋转、非整数缩放和逐列变形会改变像素簇；写成连续数学函数也可能在离散画面里撕裂。整像素平移可保持刚性部分的纹理，但不能修复原来不合格的形体。

局部变换前后同时对照完整轮廓、颈肩／衣领或膝踝接缝。需要变形的部位采用有依据的关键姿态、补绘或合格绑定，而不是一律冻结或缩小。

网页自适应缩小的整张对照图用于浏览。像素验收另看原始目标尺寸与整数倍放大；不要将非整数缩放的截图当作帧内像素组织的唯一证据。

## 识别需要换输入或换方法的信号

- 连续修订都在处理同一类身份、轮廓或接触问题，只是从头部移到衣领、再移到腿脚：回到完整角色检查，保留最近可信版本，停止追加局部参数。
- 生成器持续忽略方向或改变衣装／体型：检查该接口是否真的支持所需编辑控制。到本批约定上限后保留失败结果并调整方法，不继续用更多提示词长度冒充更强控制。
- 颜色统一后身体和材质仍割裂：需要形体、光照或完整绘制修正，不能宣称调色完成即美术统一。
- 数学检查全部通过但人物观感仍不成立：将工程结果保留为技术依据，视觉项继续标为未通过，不扩大实现范围。

一次失败只能说明本次素材与实现没有达到目标。不要据此断言所有二维绑定、生成模型或三维预渲染都不适用；推荐替代方法时也说明尚未验证的资产与工具条件。

## 可复用交付与证据

将已选身份、原始输出、淘汰候选、派生处理与实际使用资产分开记录。说明是生成、完整绘制、静态补绘、程序轮廓还是纹理取样；不要把辅助处理称作已完成的统一人物重绘。

保存参照用途、原始尺寸、相机、像素尺度、种子／提示词或绘制参数、选用理由与未解决问题。变化的资产使用独立版本文件或内容哈希；页面地址附加一个 revision 参数不能保证所有图片和图集也被固定到该版本。

交付按证据描述：完整站姿、动作候选、美术认可、程序检查、页面验证分别成立。给用户实际可查看的图像和有意义的差异，避免用一批检查数量替代视觉判断。
