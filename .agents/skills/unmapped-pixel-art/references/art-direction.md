# 美术关系与跨题材适配

## 如何读取样例

[样例原图](../assets/approved-meadow.webp) 是自有AI生成的1920×1080环境画，用于理解视觉语言，不保证某个生成模型一次复现，也不表示每处设备细节都已完成。

可提取的关系：大块天空、地面与建筑形成清楚的面积和明暗主次；受光面偏暖，遮蔽处偏冷；路径、遮挡、尺度差建立纵深；云边、草簇、屋面与服装具有不同的像素组织，整体细节尺度协调。

天空换成室内墙顶、草地换成街巷、站房换成店铺后，仍可保留这些关系。右侧站房、赭色外套、青蓝天空、雨后原野和观测用途不属于必需条件。

## 色块、边缘与像素

先用少量明度与色相组建立大形，再在焦点区补充细节。局部有限色阶是形体组织方法，不是整幅画固定颜色数量；保留必要的色温变化，避免统一量化后失去材质和光线。

硬边、高对比和较密纹理用在重要轮廓、接触与焦点，远景适当归并，安静平面少铺噪点。背景也可以成为重点，不能把远处全部糊掉。

按交付尺寸、观看距离与用途选择逻辑分辨率。严格精灵图集统一网格、整数缩放和足底基线；生成概念图应检查像素节奏，不宣称已经满足生产级统一网格。

## 光色与题材转换

| 场景 | 保留的风格关系 | 按需求变化的内容 |
| --- | --- | --- |
| 晴日自然场景 | 地形层次、受光背光、成组植被 | 地貌、植物、建筑、角色与配色 |
| 雨夜街巷 | 可辨暗部与局部暖光、有限反射 | 店铺、交通、积水、招牌与活动 |
| 室内生活空间 | 前后遮挡、人体与家具尺度、光源塑形 | 房间布局、视角、用品、角色和材质 |
| 雪地或寒冷环境 | 清晰雪块、冷暖投影与空间层次 | 沉积位置、衣着、道路和能见度 |
| 科幻或幻想场所 | 可信体积、连贯材质、有限视觉焦点 | 世界规则、物种与技术；不自动堆霓虹或魔法 |

太阳、窗光、灯光均可使用，维持光向、投影和环境反射的逻辑。夜景不必沿用日景高明度，室内不必拥有开阔地平线。

## 人物、器物与活动

身份、衣着与比例由当前设定决定，派生姿态时连续。行走和操作以重心与肢体关系区别；手持物接触手掌，线缆有端点，轮数与机械结构在同一对象的各图中一致。

门、台阶、桌椅、交通工具和路宽可作为尺度参照。人物占画面多大取决于叙事用途，不套固定百分比。

让观看者理解正在发生的事：修理铺的接件和工具、书店的整理和阅读、渡口的候船和装卸均可成为具体活动。不把生活或工作统一解释成工程观测。
