# 可回改的人物制作管线

用于把已选人物原画推进为少量姿态、有限动画，并允许持续补绘与重新导出。根据素材选择二维网格、完整逐帧、三维离线渲染或混合方法；以下经验不要求特定软件、服务、人物题材或固定帧数。

## 先复现一个完整制作片段

方法不确定时，找具备源美术、可编辑工程、真实动作与导出步骤的完整例子。在本机修改一个关键姿态、保存、重开、导出并比较，再决定是否迁移目标人物。仓库只有脚本或演示视频、缺少原资产时，只能作为方法资料。

示例跑通支持工具链可用的结论。目标人物的分层补绘、风格、非对称装备与动作自然度需要另做迁移小样。保留示例来源、版本和许可，不将其美术默认为产品资产。

## 分清哪些修改影响哪些结果

| 资产 | 承担的修改 | 回改范围 |
| --- | --- | --- |
| 身份与风格参照 | 人物比例、衣装、光色、装备归属 | 作为稳定比较依据；派生图保留来源 |
| 共享美术母版 | 原画拆层、遮挡补绘、所有姿态共用的设计 | 经骨架或姿态工程重新导出所有相关姿态 |
| 骨架／动作工程 | 关节、权重、朝向、握点、足底与姿态 | 重新产生可追踪的基础帧 |
| 姿态修绘 | 只属于某个弯曲／遮挡状态的衣褶、手、轮廓 | 叠加到对应基础帧，不画回全部姿态共用的图层 |
| 发布帧与图集 | 经选用的有限帧、锚点与播放数据 | 从制作源导出，运行时不承担补画任务 |

记录画布尺寸、原点、足底、相机和图层偏移。绘画软件经常裁去透明留白；导入时按 x/y 偏移恢复共同画布，不能把每个裁块分别缩放到一个框里。层名、层序和混合方式属于实际导入器的契约，数量与命名随角色决定。

姿态修绘绑定基础帧的内容版本。基础帧改变时先停止套用旧修绘，重新检查对齐。可对解码后的 RGBA 做摘要，避免仅 PNG 元数据变化导致误判；同时保留尺寸与制作参数。校验全部依赖后再写输出，失败时保留上一份可用结果。

## 用实际回改验证闭环

在建立或修改导入导出工具时，按其风险选做以下检查：

- 将未修改的母版回导，确认原姿态和少量关键姿态没有意外变化。
- 在隔离副本中改一小块明确可见的衣料，验证修改实际进入相关姿态输出；检查结束后不混入交付美术。
- 修改某一姿态的修绘层，确认其他姿态与共享母版不受影响。
- 保存重开工程、重新导出，确认纹理已随工程保存，结果可重现。
- 改变基础帧，确认旧修绘会被标记失效，且失败不会覆盖已有输出。

能够打开文件或导出图集，还不足以说明补绘可以经过整条制作流程。以上检查验证回改路径，美术判断另看实际画面。

## 持物与查看

先确定携带、使用与放回时分别怎样握住：哪只手、接触在哪里、掌侧与拇指朝哪边、器物哪一面供使用。提把、背握、侧握、托举都可能成立，依据该器物和动作选择；携带握法不能完成使用时，设计实际换握或调整器物，不把某一种握法推广到所有道具。修改既有器物设计时说明变化，不再宣称完全复刻原画。

用腕部、实际指根和掌面几何标定掌轴，再用拇指侧确认掌背；左右手及不同骨架的符号不能照搬。查看屏幕时，要同时读出掌面、拇指、屏幕与视线的关系。仅检查“屏幕朝脸”会放行反手。由掌侧支撑的终端，其屏幕与掌面应符合这种握法；该关系不适用于所有提把、杯柄或其他器物。

固定握持时，让完整器物随手运动；检查整个相对变换，不能只看握点中心不漂。换握、真实铰链或松握悬挂可以产生相对运动，但须有对应的接触、转轴和过渡。不能为了让器物朝向目标，在闭合拳头中添加没有依据的独立翻转。前臂旋转与腕部屈伸分别处理，不把转掌全部压到手腕。

先看携带、使用、放回的完整关键姿态；需要时补掌侧与手背的真实近景，确认拇指、其他指、支撑与固定件。近景用于结构，目标尺寸用于可读性，两者不能互相替代。端点成立后再看相邻帧及完整动作。变换、接触和朝向检查只支持各自约束，不等于人体自然度已经通过。

## 复用与导出效率

将源资产制作、姿态烘焙、帧渲染和预览打包分开。共享形体、材质或握法变化时重新生成受影响姿态；只改排版、播放时间或导出容器时复用已有帧。每批交付完整姿态、必要近景、连续片与目标尺度对照，由制作者先自查，避免把每个局部参数都变成一次用户验收。

逐帧烘焙时明确该帧来自固定基准还是前一帧累计。需要从基准重算时，同时恢复骨架、器物绑定及相关动画状态，避免前帧曲线求值被误当成新的起点。检查实际求值后的起止姿态与器物，而不只检查赋值代码。

预览编码也要核对时间和颜色。GIF以10ms为时间单位，逐帧写83ms可能被截成80ms；可按累计时间取整分配帧时长，并检查总时长。同系列帧采用一致的颜色处理，避免独立量化带来的闪烁；这些导出改进不能修复不成立的动作。

已否决的具体源或绑定可设置输入拦截，保留失败原因和替代版本；不要据此禁止所有同类资产。制作源、程序检查、制作者目视检查和用户认可分别记录。

## 先查结构，再决定补绘位置

**接缝与遮挡。** 分层初始合成先与原画比较。头颈、衣领等连续区域可以保留一张网格；需要分开时准备重叠与隐藏内容。关节两侧使用相容的变形与足够的覆盖。直接让整块裤腰随大腿转动，可能暴露尚未补齐的髋部；统一权重也不能凭空生成隐藏衣料。

拆层还需检查微小孤立像素的实际归属：属于袖缘的衣料若留在躯干层，会随另一套变形运动，产生针孔或跳点。先纠正像素所属的运动表面，再补隐藏覆盖；盲目扩张覆盖区不能修正错层。可在容易露缝的连续帧中检查封闭透明孔，但要排除手臂与躯干之间原本存在的空隙，检查结果也不能替代完整轮廓判断。

**近乎伸直的 IK。** 两段链存在不同弯曲解，小幅目标变化就可能翻膝。采用符合动作的弯曲方向、前一姿态或源姿态约束；没有改变的支撑腿可保留可信配置。结合足底、重心和相邻帧判断，不只检查骨长。

原站姿与第一动作帧也要连续比较，不能把原姿态绕过解算器、其余帧全部固定选另一分支。四分之三视角原画中的投影膝向不等于运动中的解剖弯曲方向；固定原分支也不保证迈步正确。两种选择都破坏完整腿形时，应制作可信的完整关键姿态，重新处理投影与遮挡，而不是只改变分支符号。

**蒙皮体积。** 线性蒙皮可能收窄弯曲处；保持体积或双四元数蒙皮可以作为对照候选。用同一姿态比较关节宽度、髋部鼓起、遮挡与像素组织，不将某个模式视为所有衣装的最佳选择。体积修好后，新衣褶仍可能需要姿态修绘。

不要将缺失的隐藏衣料问题改写为权重问题。为防露缝而让大片上大腿固定在骨盆上，会把有效转折推向大腿中段；再移动过渡带只是在僵硬和露缝之间交换缺陷。应先补足可编辑的隐藏结构，并在完整姿态中检查真实关节与衣料轮廓。

**变换轴。** 二维骨架嵌在三维软件中时，用画面法线确定铰链轴，并转换到骨骼静止局部空间。骨骼局部纵轴不一定是二维旋转应使用的轴。

**诊断姿态的实际求值。** 播放或渲染可能重新应用动画曲线、约束和驱动，覆盖临时设定的姿态。在隔离副本中处理驱动关系，检查实际求值后的关节点与输出像素，确认对照确实改变了预期变量；不能仅凭赋值代码已执行就解释两张结果。

**像素输出。** 最近邻采样、输出网格、相机、抗锯齿和抖色分别检查。固定种子与关闭无关抖色有助于发现真实差异；轮廓透明度、颜色转换误差与结构变形分开记录。不要为了消除一点取样误差而缩放头部或改变人体。

保持身份不能直接写成“每帧头图只能整数平移且像素一致”。这会排除应有的头部转动，可能让胸肩在固定头图下方滑动。头、颈、衣领和胸肩的空间连接先成立，再检查取样与可辨识特征；采用同一连续姿态时，可以检查实际脸部与胸部是否服从同一变换，而不能只检查参数或各自的位移幅度。已出现这种脱节时，先撤回当前动作，不能靠增加胸肩摆幅继续推荐。

**连续约束。** 工程没有持续 IK 时，在实际导出时刻重新求解支撑脚点，再保存对应姿态；仅插值关节角度可能让落地后的脚滑动。悬挂器物的握点随手，器物角度可独立参考重力。脚点固定后还应查看鞋底像素、手部接触与停步保持区；这些检查支持取样和连接稳定，动作自然度仍由完整画面判断。

**步序与位移。** 先按行进方向读源站姿的前后脚，再设计追步、交替步或拖步，不能把“左右脚都动过”当作交替行走。固定支撑脚后，仍要检查双脚相互经过、承重转换与完整身体。对每段位移都使用首尾速度为零的缓动，会使身体在经过姿态反复停顿；可将根节点行进曲线与提脚、落地、箱体回摆分别编排。连续行进曲线不等于人体质心解算，也不能补足原画中缺少的交会遮挡和脚掌滚动。

有限动作含有起步与停稳时，不能直接用作连续循环。将起步、稳定行进与不同支撑脚的收步分别处理；循环首尾减去整周期位移后，检查完整姿态、器物、鞋底和像素是否相接。形状与参数一致仍可能受绝对坐标下的浮点误差和半像素取整影响，宜在共同原点完成取样，再整体平移；几何闭合与像素闭合分别验证。技术闭合不等于动作自然或已获美术认可。

## 小样怎样放行

共享母版和少量完整姿态共同迭代。先看同一人物的完整轮廓、颈肩、髋膝踝、握持和光向，再看像素与场景显示尺度。局部修绘依照受力和材质组织色块，避免在接缝上画一条明显的带子掩盖结构问题。

完整行走不能只检查腿。根据承重与所持物编排骨盆、胸廓、肩、肘、头和器物之间的相位关系，再在目标场景尺寸同步播放；放大图上存在的小幅移动，缩小时可能完全读不出来。头部保持视线稳定，不等于冻结整个上身；两手持物也不等于肩肘和躯干可以不响应。不要给所有部件叠加同相位正弦摆动来代替完整姿态编排。

关键姿态成立后，继续检查接触、承重、经过、另一脚、停步与转向的连续关系。制作过渡时，姿态专用修绘也要有对应帧或切换设计，不能只自动插值骨架、却让修绘突然出现。

对少量局部衣褶，可试用关节附近的局部坐标记录像素簇，并按承重、弯曲和舒展阶段安排出现与收起；每个导出时刻仍绑定自己的底图。关节点只能帮助定位，不保证修绘跟随衣料表面。将进入、极值和退出阶段的相邻帧并排比较，再同步播放修绘前后两版；特别检查内部暗带、像素簇跳动与遮挡裁切。静帧变好不足以放行动画，也不要把过强修绘的闪现仅靠透明淡入掩盖。

技术复现、人物美术、完整动画和场景行为分别验收。先判断完整关键姿态，再判断相邻姿态与连续动作，最后扩展方向、帧数或场景接入。骨长、脚点、握点与导出检查只支持各自约束，不能抵消可见的人体或动作缺陷。

每次试验说明要验证的具体原因，并在同一完整人物上检查预期改善与副作用。一个部位变好、另一个部位变坏仍是失败，不作为新修正版推荐。连续修订只在挪动同一类身份或结构问题时，停止沿用该试验扩展，保留最后可信的身份参照，改用更合适的输入或制作方法；一次失败也不足以否定整类技术。

出样前由制作者完成完整人物、目标尺度与连续播放的检查，不把用户当作基础质量检查的第一道关。分别标明内部试验、制作者检查结果与用户认可；失败试验可保留复盘，但应撤回推荐。尚未具备的绘制或资产能力如实说明，不用“继续精修”掩盖缺口。
