# 叙事像素美术

产出具有绘画式光色和清晰像素组织的原创美术，题材、用途和世界观由当前请求决定。查看 [风格样例](assets/approved-meadow.webp) 理解明暗、色块、边缘与细节密度；样例中的原野、建筑、人物、服装与构图是可替换内容。

## 先明确要画什么

从请求中提取主体、用途、视角／比例、情绪、时段／气候及静态或动画需求。缺省项用适合题材的判断补齐，只在答案会实质改变产物时追问。交付目标是可查看、可使用的美术资产，不能只停在风格分析或提示词。

浓缩成简短规格：主体与空间关系、主要明暗块、冷暖关系、细节密度、像素尺度、应保留内容。将风格约束与本次场景内容分开，再选择当前可用的绘制、生成或编辑能力。

## 风格的稳定部分

- **大形有主次。** 用少量有组织的色块建立主体、前中后景和视觉落点，安静区域与细节区域形成节奏。开阔远景、紧凑街巷、室内近景均可采用这一原则。
- **光塑造体积。** 光向明确，受光面、转折面、背光面与接地投影互相解释。冷暖随光源变化；日景清澈，夜景保留可辨色阶，避免整体灰雾和全屏发光。
- **像素经过选择。** 轮廓有阶梯节奏，纹理由成组像素构成，同一镜头的角色与环境细节尺度协调。局部色阶归并形体，避免均匀铺满颗粒或直接将照片缩小当作完成。
- **材质可区分。** 云、植物、金属、石材、织物、水各有适合的边缘、色块和高光。磨损、积水、积雪发生在结构上合理的位置。
- **角色属于场景。** 默认人体连续、比例可信，衣物服从姿态，手与器物、脚与地面有接触。用户需要其他比例或物种时服从设定，不自动加入工程师和机器人。
- **细节传达活动。** 用入口、通路、使用痕迹、道具和视线组织叙事。每种题材有自己的事件，不强制加入观测、测点、探索或某个产品玩法。

详细适配方法见 [美术关系](references/art-direction.md)。

## 从规格到成品

1. 明确参照作用：风格、角色身份、构图或局部编辑目标。复用风格时改变题材内容；编辑认可画面时保留指定构图与身份。
2. 先制作决定全局的画面或关键资产，检查缩略图上的视觉主次，再检查目标尺寸的轮廓、人体、接触、光向和纹理。针对具体偏差修订。
3. 同系列衍生物沿用已选光色、角色身份和像素尺度。需要拆层时补足露出背景，检查透明边缘和遮挡。
4. 交付实际图像或已接入的结果，说明路径、生成／编辑方式和仍需处理的偏差。网页文字按用途真实排版，角色表不当作完成的动作序列。

可直接改写的模板与跨题材示例见 [生成配方](references/generation-prompts.md)，工具选择、编辑、动画和验收见 [制作与验收](references/production.md)。沿用用户已选工具和已有授权；本技能不依赖某个仓库、服务或操作系统。

## 动态按内容设计

先说明动作表达的事情，再选择制作方法。环境可以分层或局部动画，锚点与接地点稳定；人物动作需要身体、衣物和装备连贯。只有静态人物原画时保留其姿态，或另行制作完整动作资产，不用胸腹部矩形贴图位移冒充呼吸或受风。

静态画、环境动态、角色动画和可行走空间分别验收。实现到哪一级就按哪一级交付，目标项目的交互、性能与发布规则由该项目决定。
