# 裂隙前哨：场景方向与镜头推演

2026-10-27。用户明确认为上一版场景本身不理想，而不只是缺少移动、环境和角色细节。本轮回到场景构图，制作独立的可切换镜头设计样片。不是已获认可的首页替换，也不是完整游戏。

## 为什么换掉平台群

上一版由六块近似楼板与连桥组成，世界尺度虽大，主体仍像基础设施展示。每处都有同样的“抵达—说明—下一站”，章节结构替代了空间叙事。空场与雾没有提供可读的周边；终点也缺少停顿与视线方向的变化。

## 提案：局部工程嵌入远大于人的世界

前哨嵌在一条巨大的地层裂隙中。岩壁具有竖直体量、层理和断裂，不使用阅读页的山脊高度场。工程只占壁缘的一小段：遮蔽的入口、沿壁检修道、凹入的工作间、伸向断面的观测台。它们由一条连续的基础设施联系，沿途有排水、支撑、管线和维修尺度；墙与转角遮住尚未到达的部分。

整体由“一条切壁 + 依附它的工作痕迹 + 更远的对岸”建立大中小层级。近处石层承担视觉主体；黄铜标记与暖光只出现在已经使用的位置。对岸有具体轮廓，越过对岸仍有更远地层；远雾负责距离，不能代替世界。

## 同一个场景的六个镜头

1. **门外**：倾斜切壁穿过画面，近处有遮蔽的前哨，中段路径被墙体切断，远处才看见微小的外伸观测台。首屏保留书名、一句主题、进入入口。
2. **进入**：降到人物附近，从檐下沿工作面横向看出裂隙。岩壁与顶棚成为实在的遮挡，外面的世界只通过开口出现。
3. **沿壁**：镜头跟随人物沿窄路前进，路缘、支撑与层理形成视差；途中可暂停。不是在两个俯视构图之间插值飞行。
4. **工作现场**：先被实体侧壁挡住，转入后才能看到检修架和检查面。模式对照集中在这个现场，不要求六处复用同一套按钮与装置。
5. **越肩抵达边界**：人物在实体通路末端停下，相机向其肩后靠近，再朝对岸打开。画面主体从“我们造了什么”转到“前面还是什么”。
6. **回望**：从边缘看回近处路径与前哨，保留方向感和返回的可能。已走过的范围只有一小段，没有“未知清零”的结算。

这些是镜头设计样片。点击“顺序试看”播放分镜，停步控制只管理本次预设镜头；不宣称已经实现自由行走、完整碰撞或任务流。

## 人与 Agent

人在工作区域使用有明确四肢、头盔和背包的比例参照，边界镜头只有人和稀疏的标记，避免 Agent 把终点变成热闹的展示。

Agent 使用非人形、带功能名称的开放几何任务单元。AI 原生时，它们分布于不同工作面；人提供意图与必要裁决，系统门禁检查已表达条件。人类主导时，人沿工作面顺序活动，仍然保留工具与自动化。当前对照只演示空间职责，尚未接入双时代任务引擎，不能拿单元亮灯当作检查通过。

## 本轮判据

先看无标签的场景是否有主体、不同镜头是否属于同一处世界、遮挡是否随移动展开、周边是否有功能、终点是否有面对未知的方向感。性能与浏览器检查用于排除实现问题，不证明美术已被接受。暂不改正式站点，不自动提交或发布。


## 实现与验证（2026-10-27）

预览入口：`http://127.0.0.1:4395/rift.html`；`?shot=4` 直达边界，`?still=1` 用于固定截图。生产页面未修改。运行 `node prototypes/visual-direction/browser-check.mjs --rift`，37 项检查通过：单 Canvas、人物实际行进、相机跟随、中途停步与恢复、六个取景、工作区模式、真实章节链接、320 / 390 / 768 / 1440 / 2560px 三种页面状态、三次挂载释放与 WebGL 失败阅读入口。

首页静态测量 11 次 draw call、27,204 三角面；DPR 上限 1.5，渲染宽上限 1920。静止时无 RAF 循环；动画仅由镜头和行进触发，后台与离屏停止。三次重新挂载均为 17 个 geometry、9 个 texture，销毁后 canvas 与循环归零、帧数不再增加。这是资源计数与调度检查，没有测量 GPU 毫秒、功耗或不同设备 FPS。工作现场的角色网格会增加 draw call，后续需要合批或最终资产替换，不能拿首页数据代表所有镜头。

浏览器检查通过并不代表美术质量通过。人工查看中仍发现：岩壁缺少更自然的多尺度结构，建筑偏灰盒，人物比例虽能辨认但仍是程序模型，边界前方的层次与构图还可深化。手机说明压住人物，已限制说明宽度；同时补齐岩壁切面、修正顶面绕序并删除没有支撑的悬空标记。这些是最终三张截图之后的修正，只重新执行浏览器检查，没有追加截图。无 WebGL 保留说明与章节链接，尚无场景静态 SVG 替身；降级检查会有一条预期的 WebGL 上下文创建失败日志，正常切换无运行或 shader 错误。
