## 当前实现

- 首屏只保留小型站点导航、书名、一句主题与进入操作；书籍定位、版本、十章摘要和安装入口在下方。
- 山体表面承接侧光、网格和贴地路线；右侧实体在不规则边界处消退，远端仅保留未连接样本。首屏、进入和返回共用一个场景、一个渲染器、一个 Canvas。
- 六个工作站有不同轮廓。人和三台 Agent 仅在进入后出现；模式切换改变角色位置，章节始终可读。
- 普通阅读载入 `site/dist` 中的完整真实正文；左侧全书章节、正文、右侧本章目录，支持复制代码、下一章、深浅配色与返回。手机端章节导航横向滚动。
- 首屏未知区约 10 Hz 绘制，进入镜头期间跟随动画帧；减少动态偏好下保持静态。阅读、离屏与页面后台暂停连续绘制。DPR 上限 1.5，渲染宽度上限 1920；退出页面释放 GPU 资源与监听器。
- 工作站几何分材质合并，矿物凹凸与测绘光孔径在本地生成，无外部模型、图片、字体请求。当前入口使用 `frontier-world.mjs`，旧 `world.mjs` 保留为前一轮实现。

## 实现边界与后续路径

当前是构图与界面方向稿，程序几何的轮廓、材质与尺度细节仍不足以代表最终作品质量。六处空间节点用于探索入口，首页下方与导航完整保留十章。

角色切换只验证进入后的控件位置和视觉关系，尚未接入 `prototypes/dual-era/` 的委派、兼容接口、验证证据与恢复任务。不能以“换了一个模型”代替两种 SDLC 的职责差异。本文没有模拟真实 AI 概率或测量可靠性。

方向稳定后才制作最终资产：先固定两个主镜头和移动端取景，在 Blender 完成有明确用途的装置、工作台与地表；用 GLB、烘焙明暗与按设备压缩的贴图替换程序占位。保留同世界的空间关系、可读轮廓和剩余未知，再接入已验证的任务状态。是否使用后处理应由画面和设备实测决定。

候选色板为石墨夜色 `#111c22`、雾白 `#e7e4dc`、纸色 `#eeece5`、铜色 `#9b4928`、暖光 `#edb17a`。实际实现保持现有 Astro / Starlight / 原生 Three.js 技术栈。
