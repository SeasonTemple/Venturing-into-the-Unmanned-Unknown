# 行进、工作与直面未知

2026-10-27。用户指出连续区域虽然变大，却仍缺少探索过程；周边为空，角色辨识不足，两种模式没有职责差别。追加反馈：观测边界需要直面未知的分镜，整个流程不能复用六次同一种到站模板。

## 空间节奏

| 段落 | 镜头与动作 | 环境承担的信息 |
| --- | --- | --- |
| 门外 → 前哨 | 从总览下移到人物附近，靠近工作面 | 已建成的前院与基础设施，可操作的起点 |
| 前哨 → 连桥 | 人物沿桥面行进，镜头跟随；允许停步 | 栏杆和桥墩掠过前景，沟槽与服务道路位于下方 |
| 连桥 → 工坊 | 沿折线绕行，侧向观察；靠近时才见工作院落 | 墙、梁和檐下遮挡，信息在移动中逐步出现 |
| 工坊 → 验证 | 接近检查壁后停住，人物进入受光工作面 | 局部照亮，不把一束光等同于整个世界已被证明 |
| 验证 → 交付 | 越过上升段后短暂回望已经连接的区域 | 高差让已走过的路可见，保留后退的可能 |
| 交付 → 边界 | 跟随人物抵达末端，再越肩转向前方，留出停顿 | 实体桥面结束，测量桩、未闭合框架与断续测线逐渐稀疏；远雾只负责距离 |

终点不再提示“下一站”。人物留在近处，已建世界退到身后；可回望来路，也可停在边缘。正文仍直接可读，不用任务解锁。

## 周边分层

近处：成片工程地坪、排水与检修沟、沿路基础；中部：中断的服务道路、构件堆场和未闭合构架；远端：少量孤立桩点与间断结构。雾衰减远处对比，不用黑暗掩盖整片空场。未测绘不画成完整网格，也不复用阅读页山脊。

## 两种职责

人使用可辨认的头盔、躯干、手臂、双腿和背包；沿路径走动。Agent 使用非人形的开放几何单元，带分解、生产、检查的文字标识，在受委派时向不同工作面移动。Agent 是任务代理的空间隐喻，不宣称是实体机器人。

人类主导：人依次整理条件、应用变更、检查证据；仍使用合理自动化。AI 原生：人先给定约束，再委派三个单元并行处理，最后由人审阅产出。该轮只提供明确标记的流程演示，不伪造真实构建、验证或可靠性数据。两种模式都保留人的判断责任。

## 本轮实现范围

在独立 territory 候选中验证可见人物行进、途中停步、段落取景、边界越肩镜头、周边基础设施和角色辨识。模式以可操作的示意流程展示职责差别，尚非完整 SDLC 游戏。先核对镜头与流程，再决定是否值得制作最终资产；不替换生产首页。
