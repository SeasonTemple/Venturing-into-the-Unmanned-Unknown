# native-phase-anchor-v05：整帧重排候选

这版回应前几轮“只修腿部局部”的问题。姿态先按一张完整画面定义：骨盆向行进方向带动，胸廓与头部跟随，右脚全掌承重，左脚低位经过并离开地面；银箱和绿色记录器随原来的两只手整体移动。没有调用 MMX、H3 或 AGY，也没有从 v03 继续逐像素补鞋尖。

## 当前目视结论

- 支撑脚仍在原生鞋底基线上，骨盆位于支撑脚上方；
- 经过脚的最低点约在支撑基线以上 8 px，已经不会误读成两脚同时站地；
- 头、胸、肩、双手和器物作为一个组向行进方向微移，握持关系保持；
- 经过腿的下段仍偏细，膝部折面只由少量源色簇表达，长时间播放前需要增强完整腿部体积。

因此它比 v03 更接近“可继续修的完整关键姿态”，但仍不具备动作或美术通过状态。当前只保留一张静帧，不生成中间帧或视频。

## 管线判断

这次把问题从“修鞋尖”改成“先定义整帧关系”，能避免局部修复把重心、躯干和装备留在站姿。下一次仍以整帧为单位重画经过腿的宽度和膝部色簇；通过完整静帧后，才进入两帧之间的过渡试验。
