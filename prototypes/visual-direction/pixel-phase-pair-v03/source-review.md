# native-phase-pair-v03：四姿态过渡候选

本版在 v02 的两个承重端点之间加入一张手工整帧的 `left-contact`。它让右脚从全掌承重过渡到前掌支撑，同时让左脚进入低位接触；所有身体、装备和腿部轮廓都按整帧关系重排，没有使用自动插值。

## 目视结果

四帧并排后，承重顺序可以读成：右承重 → 左脚前摆 → 低位接触 → 左承重。装备仍属于同一人物，脚底基线一致。当前仍需重点检查低位接触帧的双脚先后关系，以及左承重帧的骨盆是否随负重变化；这批不能直接当作动画成品。

## 下一步

如果四帧整体通过，下一步只制作一张“经过位”中间帧，然后再做 8 帧以内的离散动作试片。若低位接触或左承重不成立，继续整帧重排，不做局部鞋尖修补。
