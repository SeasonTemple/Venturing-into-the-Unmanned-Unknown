# 空间尺度修正：从前哨进入连续世界

2026-10-27。用户指出核心问题是场景太小。上一版虽然把圆台拆成错层平台，仍然是一眼看完的微缩展台。本轮先做总图和镜头分镜，再实现独立尺度候选，保留前稿比较。

## 设计前提

一个世界单位按一米组织比例。人高约 1.7m，通行路径宽 3.2–4.5m，单个建筑 / 工作院落宽 18–26m。主探索区域分布在约 140×210m 的范围内，区域间有实际距离；它们不共同摆在一块展示底座上。外部基础设施继续超出这个范围。

世界以结构、道路、开挖地坪和基础设施建立连续性。保留工程前哨、局部照明和开放边界，不复用阅读页山脊。首屏显露入口、中程通路和远端设施；进入后靠近前哨，再沿路线逐区观察。近处墙体和廊架会遮住其他区域，远处设施受距离与雾影响，不能在任意一个镜头中读完六个地点。

## 镜头分镜

1. **首页 / 门外**：近处可见大体量前哨、通路与实体表面；视线沿路径向远端延伸。大部分世界超出画幅或处于遮挡后。书名与进入操作保持克制。
2. **进入 / 前院**：同一透视相机沿路径靠近前哨，人的高度成为比例参照。区域导航此时出现。
3. **跨区 / 连桥**：镜头沿预设安全通路越过高差，前院逐渐退到身后，桥侧结构占据前景。
4. **转角 / 工坊**：此前被遮住的廊架与工作院落进入画面；不再同时显示全部工作区。
5. **检查 / 狭缝**：靠近检查壁，能分清墙体、受光范围与工作面。抵达后可打开当前章节；全部正文保持直接可读。
6. **远端 / 观测**：已建路径结束，开放空间继续超出实体。允许返回已访问区域，探索不封锁正文。

移动使用明确的区域入口和前往下一处按钮；桌面与手机分别取景。当前不加入碰撞、驾驶或第一人称键鼠门槛。减少动态时直接到达对应观察点。

## 本轮核对重点

检查实际区域间距、建筑与人体比例、首屏 / 各区视野变化、跨区移动路径、遮挡及远近关系。交互保留同一 Canvas、真实章节、返回原观察点、键盘、手机与减少动态；检查浏览器和 GPU 资源收尾。上一版“六个标签同时在视口内”不再作为新空间的判据。

## 当前边界

用户后续明确指出，场景本身的构图、造型和整体观感仍不理想，继续补充功能不能代替场景设计。按用户要求暂停场景深化，保存阶段快照，优先将已确认的阅读设计接入正式站点。`journey-direction.md` 是未完成的后续构想；角色拆分、周边构件与边界取景的初步修改已保存，但尚未形成新的行进或双模式体验，不能视为用户验收。

这一轮交付的是空间骨架候选，解决上一版六个平台挤在同一展台上的尺度问题。建筑、人物和装置仍是程序资产，材质细节和区域叙事尚需深化；测试通过不能证明视觉已获接受。区域切换沿预设路线移动，并非自由行走或完整物理系统。模式切换目前只改变示意角色，尚未接入完整 SDLC 任务。全部内容仍在独立预览中，未替换生产首页。
