# AGY phase-study01：制作者审片未通过

本次只调用一次 AGY `generate_image`。原画负责人物身份、服装、装备、光色和机位；灰色行走代理只提供经过相位的结构参考。输出为 `candidate.jpg`，896×1200，后端型号未暴露。未生成视频、未镜像、未倒播、未做局部位移。

## 目视结果

人物脸、橙赭夹克、深绿裤和银箱大体保留，画面能读出“向左经过”的意图。前脚接近地面，后脚抬起，说明把真实行走代理作为动作参考比直接让 H3 从站姿首尾自行补步更有方向性。

但这仍不是可用关键帧：

- 双腿在膝部交叠，支撑腿与经过腿的前后关系不够清楚；
- 后脚变成明显的脚尖落地，不能证明是自然的摆动脚；
- 步幅和小腿伸展超过原画的稳定比例，身体重心没有清楚落在支撑脚上；
- 银箱仍在画面左手，但绿色记录器的横向形态和接触关系改变，不能视为原画的同一握持；
- 输出是压缩 JPEG，边缘与像素簇已经软化，不能直接作为原生像素帧。

## 管线结论

AGY 能够把“身份图”和“动作参考”合成为一张可辨识的候选，但无法稳定遵守本项目要求的膝向、脚底、重心和器物握持。结合前面两次精确落脚编辑失败，这条路线已验证为“可做概念姿态参考，不能作为精确动作资产生产器”。不再用更多提示词或同类参考图追加纠偏。

下一步应回到可编辑的完整姿态母版：用 3D 代理只提供经过和承重的关节关系，在像素源上手绘并固定脚底、膝向、掌轴和器物接触；完成一张原生尺寸的完整关键姿态后，再决定是否把它交给 H3 做短时序试验。当前候选不接入首页。
