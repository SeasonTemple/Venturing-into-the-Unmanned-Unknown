# 地形材质与半透明阅读背景调研

日期：2026-10-26。范围：资料核对、现有实现诊断与设计方向；本轮没有修改阅读页效果。

## 结论

当前缺少的不是更多网格、模糊或光晕，而是两组可被辨认的关系：山体表面的材质如何响应光，以及前景材料如何改变下层内容的观感。增加参数和特效不能代替这两组关系。

建议采用“受侧光照明的哑光测绘浮雕 + 覆在底图上方的半透明描图膜”。这是结合探索手记提出的设计方向，尚未通过新的视觉样片验证；描图膜也不是对真实描图纸光学性质的精确模拟。

## 当前地形为什么像示意图

核对文件：`journal-terrain.mjs`、`survey-field.mjs`，以及 `.lab/relief/header-final.png`。

- 高度主要由三个高斯丘陵叠加而成，峰谷圆滑，缺少连贯山脊、分叉沟谷与尺度变化。整体又施加周期起伏，更容易联想到布面或水面。
- 自定义 ShaderMaterial 用表面法线和一个固定方向做点积，再混合底色。这能提供坡面的明暗，却没有完整的粗糙度反射、微表面法线或环境照明关系。
- 当前没有地形投影或环境遮蔽，山脊对后方坡面的挡光不可见。降低暗部亮度不能替代实际遮挡。
- 网格线是独立线段材质，缺少与山体一致的受光关系；节点与路线的暖色也没有形成照在山体上的可信范围。
- 原生自定义 shader 可以做出优秀材质；这里的问题是当前模型与实现缺少这些线索，并非 ShaderMaterial 本身能力不足。

## 地形应如何设计

材质选择：偏深青灰的哑光矿物或模型浮雕，非金属，保留少量宽而克制的反射。大尺度形体负责峰谷，小尺度法线负责表面纹理；不要把随机颗粒直接叠成脏噪点。

光照组织：一个明确的斜侧主光，较弱环境填充，山脊投下方向一致的阴影。峰顶与坡面出现宽窄不同的受光区域，谷地有遮蔽但不能一片死黑。网格以低对比测绘标记叠在材质上，不能代替山体本身。

几何组织：先改出连续脊线、谷地和局部坡折，再评估纹理。固定地形形状；若保留运动，优先让光域或测绘扫描移动，避免整个山体周期鼓动。

节点的“照”：如果继续使用照明隐喻，使用受地形遮挡的局部掠光或有限光域，让邻近坡面出现可见变化；远处或背坡不应同步变亮。节点标记本身保持小而清楚，不恢复三个同样的径向光斑。范围只是叙事示意，不代表真实验证覆盖数据。

起步实现可用 MeshStandardMaterial、正确更新的几何法线、微法线细节、主光阴影与弱环境照明。若顶点仍有位移，必须同步处理法线及阴影深度材质。先解决形体与照明，再决定是否需要 AO；不默认堆叠全屏后期。

## “表层”和“下层”具体是什么

从观看者到后方：

1. 正文与导航：清晰的 DOM 文本，不参与折射或模糊。
2. 连续的半透明表面：相对稳定，轻微粗糙与纤维感，少量低频法线变化。它改变透过来的图像，也以很弱的反光表达自身存在。
3. 有间距的测绘内容：与页头使用同一地形的线索、等高线与局部测绘路径；缓慢经过表面下方，具有相对视差。
4. 干净的底色与环境光：维持阅读时的明度和色彩稳定。

关键是“下层经过材料后是什么样”，而不只是绘制顺序。强度相同的全屏模糊容易被看成失焦图片；远近不同的内容应有不同的清晰度、偏移和相对运动。表面本身需要少量可见线索，但不应变成满屏颗粒、厚重玻璃边框或反光卡片。

当前 `ink-wash.mjs` 先画二维线图，`reader-atmosphere.css` 再覆盖 `blur(2px)` 与均匀浅色。它有上下叠层，但没有表达内容与表面的距离，表面也没有独立的光学特征。固定 blur 本身可以有用；缺少的是与空间和材料关联的变化。

建议的网页实现：把下层测绘场景渲染为纹理；连续前景膜按缓慢变化的法线采样，产生小幅、连贯的折射偏移；依据设计的深度场选择不同模糊级别，再叠加克制的表面散射与反光。需要明确这是适合阅读场景的近似，屏幕空间采样有边界限制，不等同于完整体积散射。

视差用来交代间距，不要追随每次鼠标移动产生晃动。移动端可保留静态材质与低频下层运动；减少动态偏好下停下运动，仍要能看出两层。

## 与探索手记的联系

页头直接看见浮雕地形；进入正文后，像把半透明记录材料覆到同一测绘对象上，观察、标记和记录仍在下面延续。这样可以把页头与阅读区联系起来。

下层运动应有可解释的变化：局部线索被测绘光域带出，随后保留少量痕迹，而非无目的流动。正文中心通过构图保留安静区域，避免靠一块大白遮罩把效果抹掉，也避免流动亮区经过文字。

## 后续样片与判断标准

先分别制作独立材质样片与分层背景样片，再决定是否整合进阅读页。此处只是明确可评判的目标，没有宣布效果已解决。

| 检验方式 | 应看见的结果 |
| --- | --- |
| 隐藏网格与标签 | 地形仍有明确体积、表面质感和照明方向 |
| 改变主光方向 | 高光、暗部与投影同步改变，非简单颜色渐变 |
| 节点光经过脊线 | 可辨认背坡遮挡；不出现覆盖整幅图的均匀发亮 |
| 暂停所有动画 | 前景材料与下层内容仍能区分 |
| 观察数秒动态 | 表面稳定，下层运动可辨认且不干扰阅读 |
| 对照贴近与远离膜的线索 | 清晰度、偏移或视差存在有组织的差异 |
| 放回真实长正文与移动端 | 字体保持清晰，背景无大面积灰脏感，边缘无采样破绽 |

性能在样片上实测后决定。前景透射通常增加离屏渲染、模糊和纹理采样成本，不能未经测量承诺帧率。原页面保持现状，下一步评审对象应是实际材质表现，而非测试通过数量。
