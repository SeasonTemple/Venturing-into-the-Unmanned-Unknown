ART DIRECTION STUDY — WORLD / CHARACTER / ACTION

让世界先被读懂。

人在哪里，正在做什么，为什么还要向前。
从这三个问题，重新组织首页的场景与人物。

本页为参考研究与设计提案。原作画面归各权利人所有；
它们用于分析，不是本站概念图或已完成的首页。

01 / VISUAL EVIDENCE

从实际画面，拆解设计方法。

RESEARCH FINDING

形体可以简化，
用途、重心与关系要具体。

《Jusant》的衣物与旧物、《INSIDE》的剪影与落地关系、《Death Stranding》的装备和连接物，都能提供可辨认的线索。

当前原型缺少的是这些经过设计的线索。增加三角面、灯光或物件数量之前，应先让轮廓、材质和行动形成一致的语言。

依据是上述官方静帧的观察；未进行实机操作，无法据此验证完整关卡节奏或内部渲染实现。

02 / PROPOSED DIRECTION · 尚未确认

一个有具体工作的探索现场。

三种设定比较。推荐先评审 A；
保留同世界进入与完整阅读入口。

A / 建议优先

高原边缘的观测站

旧站仍在使用，一条通向盆地的观测链路中断。人带着设备抵达，远处记录器偶尔还有回传。

第一眼
近处是有门窗、遮蔽和检修痕迹的低矮站房；路径越过中景缓坡，只显露远端仪器的一部分。
具体行动
查看旧记录，检查接头和供电，尝试恢复远端数据。一次恢复让局部设施重新可用。
未知线索
回传中存在尚未解释的间断；远处可见结构仍未抵达，下一步需要新的观察。
取舍
能兼容工程与探索，情绪较开放。需克制地貌占比，避免再次做成阅读页山脊展示。
B / 对照

仍在运行的旧设施

一座巨大的工业设施只留下局部有人值守；光、声音与运行痕迹从遮挡后传来。

第一眼
站在入口外，只能看到一段可通行的检修空间与远处运转的机构。
具体行动
确认设备状态、隔离一段异常线路，进入原先无法安全接近的位置。
未知线索
已恢复部分与更大设施之间的关系逐步显露。
取舍
适合精确的明暗与镜头；容易偏向压迫或灾后叙事，需要谨慎控制情绪。
C / 对照

流动的勘测营地

一个可迁移的小团队刚完成驻扎；设备箱、移动仪器与临时基线说明这里的工作才开始。

第一眼
从有使用痕迹的营地看向尚未铺设固定设施的地带。
具体行动
装配仪器、布设采样点、比较回传，决定下一次设备与人员的行动。
未知线索
观测结果与预想不同，原有布设需要调整。
取舍
装备与行动更突出；资产种类较多，容易变成载具或物件陈列。

A 的推荐理由：一个具体场所就能容纳“观察 → 候选行动 → 检查 → 局部恢复 → 新问题”。不必先造六处工位，也不必用很长的路程填充探索。

03 / CLIMATE, WEATHER & LIGHT · 设计提案

气候塑造场所，天气改变此刻。

用户认可研究方向，并提醒环境包含气候。
下列为观测站的建议条件，尚非最终气候设定。

建议试一个凉冷、多风的高地观测站，在一场降水后间歇放晴的白天抵达。近处仍有局部湿痕，远处低云尚未散尽；云隙中的侧光让工作区域短暂显露。

长期 / 气候与场所

风留下建筑和生活的形状。

低矮站房避开主风口，入口有门斗和背风操作位；裸露岩地间分布低矮草丛与地衣。线缆有固定点，设备接口有遮蔽，衣物与工具适应野外工作。

植被与材料风化需在具体地理、季节确定后校准，不能仅凭一张雾景推断气候。

此刻 / 天气与地表

云在远处，湿痕留在近处。

降水后的积水只在凹处，背风面与檐下保持不同干湿状态。低云停在盆地与山口，站房和路径仍有清楚轮廓；前方留有部分可辨认的目标。

不默认持续下雨，不把整个世界埋入均匀浓雾。未知还来自观察不足、遮挡与尚未解释的线索。

光照 / 行动与感受

同一阵风，联系前景和远方。

云层移动改变远处明暗与局部日照，风向由草、衣摆和小型风向标共同表达。人在背风处展开记录，在开阔处停下观察；局部暖色工作灯提供可辨认的使用痕迹。

这是环境与动作设计，尚未实现气候模拟。天气不直接决定检查通过，也不自动把远处信息变为已知。

首屏 站房清楚可辨，云影沿远处地表缓移。

工作近景 檐下的干燥面、外侧湿痕和风声形成内外差异。

边界停顿 离开遮蔽后风感增强，低云间露出尚未抵达的线索。

先用同一场所的稳定天气片段校准三张关键画面。云、光、风和地表状态应相互吻合，再决定需要哪些动态效果；本页原作静帧分析不用于推断这些气候机制。

04 / CHARACTER & EQUIPMENT BRIEF

先设计身份与动作，再制作模型。

以下是 A 的造型要求提案，
尚不是已完成的角色设定图。

THE FIELD ENGINEER

能看出重心和工作状态的人。

建议接近成人的自然比例。用外套、裤腿、鞋、头发或帽沿形成连续轮廓；肩部、腰部与关节避免零散胶囊拼接。

装备只保留有用途的随身工具、短背包与手持终端。三种姿态先看清：负重行进、俯身检查、停下观察。近景需要手和器物真实接触。

检查方式：移除姓名标签后，仍能认出人在做什么，以及身体如何承重。

THE DELEGATED TOOL

从作业方式识别 Agent。

建议先试一台低矮的巡检车：轮组适应通路，工作臂能靠近接口，传感器有明确朝向。固定记录器属于环境设备。

实体设备是 Agent 的行动载体；意图、任务边界、候选产物与失败证据还需交互表达。人类主导时合理保留工具和自动化，不能仅靠显隐车辆表现两种职责。

检查方式：移除“AI”字样，仍能看见委派、执行、待检查与人的必要裁决。

05 / THREE KEY FRAMES TO DESIGN NEXT

先把三张关键画面做对。

  1. 01 / 首屏

    认出有人在这里工作。

    站房与环境有明确主次；书名有稳定留白；远处有可辨认但未完全揭示的目标。

  2. 02 / 近景

    看清一次检查。

    人物、工具、接头与读数形成完整关系；能辨认候选接入和已检查状态。

  3. 03 / 边界

    已恢复的范围，在身后。

    前方保留新的具体线索；机位与停顿来自当前行动，不将越肩镜头固定成唯一答案。

这些是下一阶段构图任务。本页没有把文字方案或原作截图冒充本站视觉稿。
