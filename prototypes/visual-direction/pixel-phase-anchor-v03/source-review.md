# native-phase-anchor-v03：原生像素经过姿态候选

本次没有调用 MMX、H3 或 AGY。输入是已认可的 156×348 `actor-front.png` 分层源；上身、手、银箱和记录器保持同一组像素并整体微移，右腿保留原鞋底作为支撑，左腿从源像素中拆出上段和下段，围绕膝部做一次最近邻旋转并抬高。输出仍是静态研究帧，不是动画。

## 制作者复核

与 `pixel-phase-anchor-v01` 相比，这版在原生尺寸能读出一条竖直支撑腿和一条向后经过、离地的腿，双脚没有合成一团；上身、箱体和记录器的相对关系没有被生成器改写。4 倍图上像素簇仍保持最近邻阶梯。

仍有两个未通过点：

- 经过腿的鞋尖向下，脚掌滚动和踝部受力尚未画清；
- 膝部只靠少量源色簇桥接，缺少明确的布料转折，不能把这张帧当作最终动画锚点。

因此状态保持 `candidate-pending-visual-review`。它证明“先锁定上身与装备，再在原生腿部像素上做有限姿态修绘”比生成器同时猜身份和动作更可控，但还没有达到首页接入标准。

下一次修订只处理经过脚的脚背、鞋底和膝部折面，并在同一张原生对照上检查支撑脚、骨盆和装备；不扩展成帧序或 H3 视频。
