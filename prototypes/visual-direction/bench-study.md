## 用户纠正与素材来源

用户指出 `.lab/bench-study/preview.jpg` 中 Quaternius Universal Base Characters 的卡通比例、面部和形象与参考不符。此图是素材调查留下的官方宣传预览，未用作本站美术，未下载或导入其 3D 模型。它不是人物方向依据。

本轮模型是代码生成的连续衣身、弯曲衣袖、手部与器材，未使用第三方人物模型、AI 生成图片或纹理。织物、木纹与面板标签由本地 Canvas 生成。人物仍显得生硬，布料褶皱、面部、衣物结构与自然姿态尚不足以作为最终资产；越肩构图用于组织工作视线，不能替代角色造型验收。

参考维度分开：Jusant 的形体概括与环境用色，Death Stranding 的装备与行动关系，INSIDE 的构图克制。没有宣布主画风已确定，也不将三个作品等量混合。

## 这次实际改变

- 一手接近锁环，一手承托导线，双臂围绕实际接点摆放；仍需进一步改善握持的自然程度。
- 检查器具包含外壳、密封层、固定件、连接器、锁环、护线套和线缆去向。
- 工作台在檐内，降雨与地面水纹位于檐外；雨歇移除雨线与檐滴，保留湿地。没有把室内工作台整体涂湿。
- 机位收束为越肩工作近景与接点细节，保留右侧外部环境的局部视野。
- 静态模型按材质合并且保留 UV，避免织物与木纹因合批丢失。
- 一个 RenderPass、一个 SSAOPass、一个 OutputPass；已核对本项目 Three.js 0.186.1 的 SSAOPass 只合成 AO，需要前置场景色彩通道。阴影缓存，默认不持续绘制。

## 验证

`node prototypes/visual-direction/browser-check.mjs --bench`：19 项通过，无浏览器或着色器错误。覆盖两机位两天气、390/768/1440/2560 宽度、44px 按钮、暂停、减少动态效果、离屏暂停、三次挂载释放。功能检查不证明美术质量。

包含色彩、AO 法线与阴影更新的一帧：工作雨态 **108 calls / 187254 triangles**，雨歇 **97 / 184734**；细节雨态 **94 / 184706**，雨歇 **93 / 184706**。合批前工作雨态为 225 calls；最终数据来自 `.lab/bench-study/browser-report.json`。这里包含多个渲染通道，不能将其当作单遍场景三角形数。提交渲染命令的 CPU 耗时不作为 GPU 帧率。

重复挂载资源数量稳定（28 geometry / 19 textures），卸载后 Canvas、循环及后续绘制均归零。仍超过历史生产首页性能预算，仅用于局部试作。
