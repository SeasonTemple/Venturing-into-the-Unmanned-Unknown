## 三维章首、路线溢出与安装区修正

用户认可阅读方向，随后指出路线栏出现原生滚动条，建议章首尝试三维网格与粒子峰谷，并要求首页“安装与下载”直接展开、改善原始样式。

### 路线溢出的根因

旧链接使用 `width: max-content`，再叠加错位的左边距；即使 `max-width: 100%`，总宽度仍可能超过栏宽。外层 `overflow-y: auto` 又让另一轴成为可滚动轴，所以较长章节名会触发横向滚动条。原先只验证了整页宽度，未检查路线内部，这一遗漏已补齐。

当前链接宽度扣除错位边距，文字按实际栏宽换行。路线不再设置独立滚动容器；若其实际高度超过视口可用高度，则停止吸附，随整页滚动。未通过隐藏滚动条裁掉链接。

### 三维阅读插图

《验证》章首使用独立的原生 Three.js 插图：确定性高程生成网格峰谷，已知网格在边界外逐渐散为稀疏样本点；证据路径和三处 DOM 标记随相机投影定位。边界不是测得的概率，图中没有假造的成功检查或真实探索进度。

鼠标移动产生有限的轻微视差，停下即停止绘制；没有循环漂浮。降低动态效果时保持静止，插图离屏、页面隐藏或专注阅读时暂停。不可用的 WebGL 保留原 SVG 和完整正文。缩放处理实际容器宽高，DPR 上限桌面2、手机1.5；销毁释放几何、材质、上下文及监听器。

这是章首阅读插图，尚不是可进入的首页世界。首页圆台仍只验证进入、职责控件和章节打开，缺少有意义的空间行为，未被接受为最终作品。后续首屏需要围绕探查地形、局部显现、带回线索、建立证据路径和剩余未知编排动态；不能以章首插图替代这一工作。

## 地形主导、同步导航与雾面下的流动

本轮回应四处反馈：铺满画布后地形仍被文字挤到底部、导航配色割裂、页边签过长且缺少首尾跳转，以及背景应有一层雾面盖住下面的流动。以下替代前述文案优先的取景和扩散墨点表现。

- 页头标题缩为上方短信息区，去掉左侧大面积遮罩；地形取景上移到中央，主画面横贯页头。390px 保持整幅场景高度，靠近并裁切地形，标题两字横排，不再把完整地形缩成底部插图。裁切外的标签隐藏，保留视野内的模型、证据及未知边界。
- 顶部样张栏和站点导航延续章首深色。地形离开导航下方后，吸附导航转为半透明雾白；回到章首恢复。专注阅读使用正文配色，其余章节继续按各自章首配色显示。
- 原168px长的小节入口缩为52px，连同上下跳转构成约126px的工具条；粗指针设备扩大上下按钮，整体约142px。目录仍可悬停、点击固定、键盘和触屏展开。上移直达页面顶部，下移直达实际章末；焦点随跳转进入标题或章末，抵达端点的按钮禁用。
- 层次从深到浅依次为：纸色底 → 连续青灰流场与少量暖色 → 60%雾白、26px模糊的透明面 → 正文与批注。模糊面是独立层；文字保持清晰。流场以连续曲流和少量细丝缓慢变形，延续地形的流向与路径色。2D画布背板最长宽度1280px、目标上限12次绘制/秒。暂停、系统减少动态效果、后台暂停与专注阅读继续生效；不支持背景模糊的浏览器直接模糊流场。

验证使用 `browser-check.mjs --terrain`，79项通过；`--reading` 24项、`--journal` 23项通过。覆盖390、754、767、1024、1251、1440、1600、2560px的相关布局，新增页头文案比例、导航配色、独立模糊层、短目录签和真实首尾跳转检查。流场1.8秒前后比较实际像素。对比度下界按完全不透明的最深流场、CSS饱和度矩阵及实际雾面透明度保守计算，正文约6.79:1、批注4.72:1、链接4.73:1。GPU释放、WebGL回退、原文章节内容与顺序检查继续通过；不以这些检查宣称设计已获用户接受。

通过 `scripts/shot.mjs --batch` 分两批共6张，第一批检查构图，第二批为最终页头、手机及2K正文。两批均用独立Chrome并按精确进程树清理；检查浏览器也均无残留。最终图片位于 `.lab/survey-surface/header-final.png`、`mobile-final.png`、`reading-2k-final.png`。此轮未增加第三方截图，未改生产站点或首页探索世界。

## 正文入口与清晰流动

用户截图指出正文上方独立的“正文 / 本章定位”横栏突兀，回顶误将人带回三维页头，背景也只有淡灰脏色。上一轮将像素变化与可感知的流动混为一谈，以下调整替代其相关设计结论。

- 手记模式隐藏重复的定位横栏，收紧第一节上方留白。页边上箭头及章末返回均改为“回到正文开头”：将第一节标记放在固定导航下方24px，焦点进入第一节标题；到达正文开头后禁用上箭头。页头不再是这个操作的目的地。
- 用近白底 `#f7f9f6` 替代偏灰黄底色。背景只保留分开的青、蓝两股流带；亮部沿曲线向前移动，横向速度约每秒视口宽度的12%，流带自身缓慢弯曲。取消灰褐叠色，流带之间保留大块干净底色。
- 雾面由60%/26px改为约28%/16px，底下的方向变化和亮部能穿透表面。最终2D透明度统一限制在58%以内；即使多个亮部重叠，保守估计正文对比度仍≥9.07:1、辅助和链接≥6.31:1。暂停、减少动态效果及后台暂停仍有效。

`--terrain` 81项、`--reading` 24项通过。离屏停止检查改用第二节定位，确保地形真正离开视口；旧检查依赖已移除横栏的占位高度，正文首部仍在屏幕内时不能称为地形已离屏。

本轮通过统一截图入口共生成3张，位于 `.lab/flow-revision/`：`reading-a.png`、`reading-b.png`、`mobile.png`。前两张固定在同一滚动位置，分别显示动画0秒及1.8秒，以便比较运动而非滚动；实际渲染结果（包括雾面）按8px间隔采样19,264点，其中36.4%的点至少一个RGB通道变化≥6，最大差42。此为确定性时刻对照与人工看图，不冒充真人感知实验。浏览器按所属进程树清理，残留0。当前改动仍限阅读样张。

## 全章测绘页头与证据光域

用户要求背景与页头的测绘网格风格建立关系，并指出只有《验证》有完整页头，分层图版及地形节点也没有体现文案中的“照”。本轮将这些作为同一视觉语言调整，替代上节独立青蓝流带。

- 新增 `survey-field.mjs`，三维页头和二维正文底图共享同一高程、已知边界及三个路径节点。正文底图显示随地势弯曲的网格、据高程提取的等高线与未知侧采样点；窄扫描光带经过时局部提亮，再淡回静态底图。雾面保留约28%透明底色，模糊减至2px，让网格可辨；依然位于正文文字之下。扫描表现逐步探明的过程，不代表实际阅读进度或验证通过率。
- 十章都接入统一测绘页头。`chapter-surveys.mjs` 按章设置引言、三个节点及未知侧文字，例如设计章是“分解 / 契约 / 决策”，实现章是“契约 / 模块 / 代码”。使用同一片地形延续全书世界，各章尚未制作十套独立资产。长标题单独适配窄屏；《验证》的正文旁注与图版不复制到其他章节。
- 三维节点附近的表面和网格使用空间衰减变暖，并叠加贴合高程的光域。光域裁切在已知边界内；边界外稀疏点保持冷色。这里采用材质光域与几何光晕表达“局部证据照亮局部地形”，无额外阴影贴图和后处理，不是物理光学仿真。
- `layer-plate.mjs` 替换原先仅移动一条轮廓的图版：六张网格切面对应 L0–L5；切换同步改变光束落点、被照亮的切面及局部虚线覆盖区，并展示该层的问题、工具、可核对产物和仍未覆盖的条件。说明明确层号是观察角度，一层的证据不能自动照亮其余层。图例移到可读的HTML文字中，避免缩成图内小字。

验证：`--terrain` 112项、`--journal` 23项、`--reading` 24项通过。新增逐章1440/390px页头检查、全部十章原文顺序比较及六层光束/光域/证据同步切换检查。实际三维16个draw calls、6,460个三角面、624个粒子、15份几何、0张纹理，三次释放后资源为0；无WebGL时仍保留可读SVG。正文背景1.8秒采样约11.5%的点透明度变化≥3/255，最大差87/255。按最深来源色及透明度限制保守计算，正文对比度≥8.24、批注/链接≥5.73。

截图仍走统一入口，分两批共6张，每批一个所属Chrome进程树，结束残留0。最终文件在 `.lab/survey-light/`：`design-header-final.png`、`layer-light-final.png`、`long-title-mobile-final.png`；首批记录《验证》节点光域和正文测绘底图。检查通过不能替代用户对视觉表现的评审。范围仍为独立阅读样张，生产站点尚未切换。

## 侧光地形与局部底图

用户明确否定上一轮背景效果，并圈出三个黄光斑与黑底标签：叠加光晕没有组织光源、地形、路径和标注的关系。这次撤掉该处理，不把功能验证当作视觉质量的依据。

- 移除三个圆形光域及材质内的径向金色染色。地表根据位移后的表面法线计算侧向明暗，亮坡面、暗坡面和弱冷色补光共同表现峰谷；路径周围保留有限暖色。没有添加物理投影或阴影贴图，背光面的明暗不宣称为光线追踪结果。
- 网格减为隔行采样，移除无意义的斜线，降低线条亮度；样本点由624减少至290并缩小。节点改成“序号＋名称＋引线”的地图标注，撤掉黑色矩形底框；暖色路径是主要连续线索。
- 正文底图采用放大的局部取景，完整地图轮廓裁切在画面之外。扫描显影仍保持；中间阅读区域通过连续渐隐保留较低密度，两侧保留更多地势线索。移除左路线栏重复的等高线装饰，避免两套地图同时叠加。

本轮 `--terrain` 113项通过，含十章1440/390px页头、原文完整性、统一暂停、减少动态效果、首尾跳转、SVG回退与资源释放。新增检查确认正文区平均底图透明度低于页边；此前要求大面积穿过正文的断言不再作为目标，保留实际1.8秒像素变化检查。三维实测12个draw calls、3,464个三角面、290个样本点、12份几何、0张纹理；三次释放后资源为0。
