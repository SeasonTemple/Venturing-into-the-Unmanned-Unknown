## 结构的变化

路线为“辨明边界 → 采集证据 → 追踪反例 → 带回方法”。它是阅读组织，不是完成状态；访问章节不代表掌握或通过验证。全书十章、小节、代码与表格仍开放。

第一张图版允许切换 L0–L5，逐项查看要回答的问题、方法和剩余条件。第二张图版索引原文的写锁例子，从互斥与超时到协议、关键路径、测试及回归。两者均为阅读辅助，不是实际检查报告、概率模型或已执行实验。原文章节的措辞与顺序保留。

宽屏让图版和工具表展开，长段落、列表仍限定为 72ch。页边按小节定位，而不是全部固定在同一条右侧菜单里。窄屏将四段路线收为短索引，批注跟随原文；专注阅读收起路线、章首、图版与批注。

## 三维章首、路线溢出与安装区修正

用户认可阅读方向，随后指出路线栏出现原生滚动条，建议章首尝试三维网格与粒子峰谷，并要求首页“安装与下载”直接展开、改善原始样式。

### 路线溢出的根因

旧链接使用 `width: max-content`，再叠加错位的左边距；即使 `max-width: 100%`，总宽度仍可能超过栏宽。外层 `overflow-y: auto` 又让另一轴成为可滚动轴，所以较长章节名会触发横向滚动条。原先只验证了整页宽度，未检查路线内部，这一遗漏已补齐。

当前链接宽度扣除错位边距，文字按实际栏宽换行。路线不再设置独立滚动容器；若其实际高度超过视口可用高度，则停止吸附，随整页滚动。未通过隐藏滚动条裁掉链接。

### 三维阅读插图

《验证》章首使用独立的原生 Three.js 插图：确定性高程生成网格峰谷，已知网格在边界外逐渐散为稀疏样本点；证据路径和三处 DOM 标记随相机投影定位。边界不是测得的概率，图中没有假造的成功检查或真实探索进度。

鼠标移动产生有限的轻微视差，停下即停止绘制；没有循环漂浮。降低动态效果时保持静止，插图离屏、页面隐藏或专注阅读时暂停。不可用的 WebGL 保留原 SVG 和完整正文。缩放处理实际容器宽高，DPR 上限桌面2、手机1.5；销毁释放几何、材质、上下文及监听器。

这是章首阅读插图，尚不是可进入的首页世界。首页圆台仍只验证进入、职责控件和章节打开，缺少有意义的空间行为，未被接受为最终作品。后续首屏需要围绕探查地形、局部显现、带回线索、建立证据路径和剩余未知编排动态；不能以章首插图替代这一工作。

### 默认展开的安装区

- 独立标题与版本信息，左侧为安装命令，右侧为技能包、源码和全书文件，底部提供索引与全文入口。
- Windows / macOS / Linux 命令切换与复制可直接操作。命令先克隆指南，再创建目标项目的 `.agents/skills/`，从克隆目录复制技能；保留 `.claude/skills/` 与 `.cursor/skills/` 的说明。没有执行安装、克隆或覆盖用户项目。
- 接近安装区时查询公开 GitHub Release；只有实际返回且校验为 GitHub HTTPS 的资产才成为直接下载链接。API 不可用则保留 Releases 入口，文件名与大小不捏造。截图中实际返回 v0.0.2 的技能包、源码与 BOOK.md。
- 手机保留完整命令，代码区域可独立横向滚动并有键盘焦点；这与不应滚动的章节路线区分处理。
