# native-phase-pair-v01：相反承重整帧候选

这次把 v06 的整帧关系扩成一对相反承重姿态，仍没有调用 MMX、H3 或 AGY。两帧都从同一套 156×348 原生分层源合成：上身、头、双手、银箱和记录器保留同一身份与装备关系；支撑腿使用对应的源鞋底，经过腿整帧重排并抬离地面。

## 目视结论

`right-support.png` 中右脚全掌承重，左脚向后经过并抬离基线；`left-support.png` 中左脚承重，右脚向画面左侧经过并抬离基线。两帧放在同一张 4 倍对照图上，人物尺度和上身装备关系连续，动作意图已经比单帧局部修订清楚。

当前仍有一项阻塞：左承重帧的经过腿下段与鞋底比例还需要整体复核，不能直接把两帧当作完整步态，更不能自动插值成动画。两帧保持候选状态，未接入首页。

## 管线判断

这次验证了有效的工作单位应该是“相反承重的完整姿态对”，而不是连续修改同一只脚。后续先对两帧共同检查骨盆高度、腿部宽度、鞋底方向和装备接触；通过后才制作一个过渡帧或短动作试验。
