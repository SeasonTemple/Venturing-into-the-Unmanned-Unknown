# 裤脚—鞋帮接缝复核（2026-10-31）

本研究修复截图中实际可见的断踝问题，不是新的动作完成版。

## 可确认的问题

`pixel-phase-coupled-v02/right-through.png` 和 `left-touchdown.png` 的左裤脚与左鞋帮分别渲染，裤脚末端独立写死，鞋子围绕踝点转动。两层没有重叠，透明横缝在缩小后仍可见。制作时没有先在原生像素尺度检查连接，就将小尺寸缩览和变化量当作进展依据。

此前 v03 又把原图两脚最低点之差直接当作错误，拉长整腿对齐 y=373；这不能证明支撑接触正确，也没有解决断踝，现已撤回推荐。三分之四视角中，不同纵深的双脚不必具有相同屏幕 y 坐标。

## 本次修改

- 回到未经腿长归一的 v02 输入，只处理两张确定断开的帧。
- 裤脚终端由源图裤脚边缘经鞋子同一踝点与转角变换得到，裤腿轮廓延续到这个边缘。
- 只改左裤腿层，鞋子、支撑腿、上身和器物全部保持逐像素相同；没有改变画布落点。
- 保存两帧 PNG、分层 ORA、可复现 recipe 和整数 4 倍接缝对照。

`seam-before-after.png` 左列是断开旧帧，右列是连接修复；旁边小图只提供全身上下文，不承担像素验收。
