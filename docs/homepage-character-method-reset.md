# 首页人物制作方式调整

## 判断

`character-master-v03` 证明了同一三维资产可以重复修改肩线、腿部方向、材质和相机，但画面仍不能读成原画中的那个人。问题已经超出 AO、头部比例和单个关节参数：三维 NPR 的连续曲面、光照渐变和默认人体姿态，持续把身份和像素簇变成另一种视觉语言。

因此 v03 退回为结构参考，不进入首页、动作图集或四姿态制作。保留它用于测量大致体积、设备归属和相机关系，避免把“可编辑”误报为“可用”。第一份像素原生边界试验见 `prototypes/visual-direction/pixel-native-master-v01.html`；它仍把完整原画锁在底层，暂不假设被遮挡区域已经画好。

## 下一条制作管线

最终人物改用**像素原生分层母版**：

1. `actor-front.png` 是不可变身份参照，先锁定头顶、颈根、肩线、髋部、膝踝、鞋底、衣摆和两个装备握点。
2. 在 4 倍工作画布手工建立完整分层：头发／脸、颈肩与外套、左右上臂、左右前臂与手、工具箱、记录器、骨盆、左右大腿、左右小腿、左右鞋和地面接触影。每层最终回到原生整数像素，不使用模糊或非整数缩放。
3. 先只做朝左站姿和偏正面站姿。两张图必须在原生尺寸读成同一个人；看不成立时回改共享层，不扩方向和帧数。
4. 通过后才做四个完整关键姿态：右腿承重、左腿前摆、左脚跟落地、换到左腿承重。身体、衣物和装备一起检查；需要改变轮廓的部位直接在关键姿态层补绘。
5. 连续帧和首页移动最后接入。二维骨骼只负责可保持刚性的部分；膝、衣摆、袖口和手持接触由关键姿态补绘约束，不能用统一正弦摆动或独立瞄准关节代替。

## 验收门槛

- 原生尺寸先过：脸、肩胯、膝踝、鞋底和握持一眼可读；三倍放大只用于查像素簇。
- 每个关键姿态同时看完整轮廓、承重脚、骨盆、胸廓、肩肘、头和装备；任何一项错位都退回姿态，不用局部贴片遮盖。
- 只有通过的四姿态才允许生成中间帧；只有完整短片通过才允许接首页。

这一调整不是重新选择站点风格，而是把已认可的像素角色作为制作源。三维资产继续保存，作为结构测量工具，不再承担最终画面和动作身份。
