## 从两步候选推进了什么

前一段两步包含停稳，首尾脚位不一致，不能直接用作循环。新一轮分为起步、32 帧交替步、左脚落地收稳、右脚落地收稳四段。连续步每周期向左位移 86 个源像素，每段的位移与图集来自同一份输出数据。不是把旧视频循环或镜像；也没有据此宣称人物美术已通过。

每只脚分别记录脚跟落地、脚掌放平、脚尖离地与摆动，循环中两次同侧着地的距离一致。前一小样中的右脚落地位置不足以闭合周期，已在新配方中重新安排，旧导出保留。

绘制改为在共同原点取样，再将整个角色平移。否则同一个姿态即使参数相同，也可能因浮点误差、半像素取整与绝对变换位置产生不同边缘。新生成器通过可选参数启用这一方式，旧有限小样保持原行为。

新结果检查了起步→连续步、连续步的周期首尾、连续步→左收步、连续步→右收步：消除世界位移后，这四处连接的 RGBA 像素一致。另检查全部新帧的提箱侧肩袖透明孔，以及导出时的头部与鞋底约束。这些结果不能代替人体轮廓和动作自然度的评价。

## 实际交互

- 聚焦画面后按住左方向键行进，松开或按 Esc 请求收步；在下一个左右脚落地时接对应收步段。
- 点击人物前方门前石地，或选停点自动行进；按左方向键可接管自动行进。任意路面目标会在临近的完整落脚处停下。
- 停稳后再次出发，使用相同脚底锚点将承重姿态释放到连续步。当前释放段复用收稳段的反向取样，包含少量重心回移；独立起步的肩箱受力仍可进一步制作。
- 暂停或空格冻结现场；后台不累计补帧。停住后不保留动画循环。
- 减少动态默认跟随系统：选择停点时静态摆放，方向键每次移动一个停点量，不播放行走。
- 目前只有朝左的方向。没有用朝左人物倒退或翻转装备来伪装返回；“重置场地”明确重新摆放角色。

人物位移在动作采样之间按时间插值；像素动作按 16fps 采样。背景是独立静态 CSS 图层，不在每帧重绘。原尺寸近看只在动作帧改变时刷新。四张图集和一张背景只解码一次。
