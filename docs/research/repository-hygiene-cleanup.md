# 仓库素材清理与入库边界

2026-11-02。过程素材曾被错误地作为“可复现资料”提交，造成源码仓库膨胀。已将退役候选、批量抽帧、重复预览、中间模型/姿态工程、原始日志和技术检查输出从维护分支及标签历史中移除。

## 保留什么

- 章节、网站及必要的制作/检查源代码、参数化源配置、精简研究结论与来源。
- 已有页面依赖的生产资源、已发表文档使用的有限插图。
- 当前人物身份参考、当前人体观感获确认的完整静帧及最少调用证据、实际使用的姿态参考、完整分辨率可编辑身份源。

所有保留媒体/特殊源文件的精确路径及用途见 `config/repository-assets.json`。保留当前静帧不等于美术、动作或首页放行。

## 归档与恢复

退役资料没有作为 ZIP 再次提交。本机在仓库外保留一次本地研究归档，包含 `research-history.bundle`、逐文件 SHA256 清单和清理前未提交差异；该归档不属于仓库或下载依赖。必要时将 bundle 克隆到另一个临时目录查阅，不要把它导回正式分支。

历史原型源码和记录保留用于阅读方法，不保证删除实验资源后的旧审片 HTML 能独立运行。相关旧链接已改为归档路径文字；正式站点资源独立保留并单独构建验证。历史实验不作为当前产品依赖。

## 固定纪律

过程输出写入 `.scratch/` 或 `.lab/`，依赖、缓存、抽帧、录屏、请求日志、失败候选和中间工程默认忽略。正式资源只允许按精确路径登记；禁止为了让检查通过而登记临时产物、放宽预算或绕过钩子。

单文件默认上限 2 MiB；当前跟踪树与全部可达历史的唯一 blob 各以 25 MiB 为预算。检查覆盖完整暂存区，故 `git add -f` 无法使未登记产物通过。新增大型正式制作源须先由用户明确存储方案。

匿名提交纪律继续有效。重写后的分支/标签不再引用退役素材，但 GitHub 旧对象缓存、既有克隆和本地恢复包可能仍保留旧内容，不能把重写宣称为全球删除。
