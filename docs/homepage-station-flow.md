# 观测站现场对照与风向修正 · 2026-10-27

用户确认继续“进入观测站 → 查旧记录 → 对照现场测点 → 得到下一条线索”。沿用已认可的原野原画、人物身份、光色和建筑，不扩建场景。本次接入第一段现场对照，角色仍为静态站姿。

## 体验

进入后可点檐下记录，或用画面下方按钮查阅。旧记录描述“旧桩在维护路右侧、风标在上游水弯旁”，且缺少日期。两个现场标记对应画面真实可见的临水旧桩和上游风标，允许任选顺序查看：旧桩实际上在维护路左侧，风标与水弯的关系仍吻合。避免在没有罗盘的画面中凭空断言东西岸。

两处都看过后出现对照；主动留下线索，才记下“补定位、查桩位迁移记录，暂不延伸地图”。不据此断言原因已查明。完成后可阅读真实的“验证”章节。重读记录保留发现，退出再进入保留当前页面的进度；“重新核对”才清除。刷新或跨页不持久化。

热点采用贴地细环，悬停／键盘聚焦显示深绿小标签，已查看状态变色。全部操作都有原生按钮替代路径；Esc 优先关闭搜索，再退出观测站并恢复入口焦点。701–1200px 将手记放到画面下方，避免覆盖测点；手机仍只加载满屏静态原画与阅读入口。

## 云与资源

旧版正弦云层会往返，24fps 上限叠加整数像素采样会产生跳动。现在以每秒6个原画像素持续向右平移，与草、水同用一次 WebGL 绘制。目标60fps，保持1440×810缓冲上限，不随DPR增长；离屏、搜索、用户暂停、后台和减少动态设置均停止调度。

天空由已认可原画离线补齐屋顶遮挡区，使用云内部的完整像素块匹配，不拉伸扫描线。1920×576纹理在Shader中虚拟镜像延展成3840px周期，约640秒重复；镜像的是纹理形状，运动方向始终向右。仅上传一份天空，约269KB，GPU纹理约4.22MiB。相对实际存储双宽纹理减少一半天空显存与约310KB下载。仍有重复／镜像的云形，不是气象模拟。

遮挡遮罩从宽矩形改为原画物体轮廓，保护天线、屋顶和烟囱，避免旧天空随包围盒固定成块。亮云像素另作容差处理，消除残留亮点。天空、遮罩均由 `node site/scripts/build-meadow-sky.mjs` 可复建；没有新增生成图片或视频调用，没有引入运行时依赖。纹理尺寸超出设备限制时退回静态原画。

首页文档滚动条采用浅草绿轨道与深绿滑块，保留原生页面滚动；不在首屏内部新建滚动区域。

## 核验与视觉记录

本机Chrome在1440px视口实测约60fps，P95帧间隔约17ms。CPU提交均值约0.03ms，此值不代表GPU耗时，也不保证所有设备帧率。基线一秒约20次绘制，上限24fps。

首页43项检查全部通过，覆盖云层在0／80／190／400／639秒的实际像素平移，含循环边界；向右对齐误差接近零，排除停转或反向。另检查固定人物／建筑像素、单次绘制、320–2560px布局、现场观察顺序与重读、保留／重置、键盘、搜索优先级、离屏停止、静态手机、无JS和无WebGL降级。10章正文与源文件逐字节一致，构建资源引用验证通过。

本轮共6张浏览器截图，全部通过 `scripts/shot.mjs --batch`，未另开常驻浏览器。浏览器行为测试和截图都精确结束各自的Chrome PID树并删除profile，残留进程0。机器记录在 `.lab/meadow-production/browser-report.json`，截图与离线遮罩合成核对在 `.lab/survey-pins/`。
