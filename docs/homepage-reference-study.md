## 画面拆解

### Jusant：简化有设计依据

Gameplay 7 通过近处岩层与化石、中层旧梯架、人物及狭缝亮部建立层次。细节有大小与密度区别，旧物让环境带着使用历史。Gameplay 10 的分层外衣、靴子和脚底阴影将角色连为可信的整体；Gameplay 1 以支架、管件和岩层的不同形体建立构筑物关系。

借鉴：先用大形安排轮廓和材质区，再放少量说明用途与历史的物件。人物先校准身体和服装连续性。不能把这种删减理解为简单堆叠几何体，也不能仅靠 Toon 量化或噪声得到同类完成度。

### INSIDE：尺度、姿态与遮挡

截图 01 中人物面积很小，红衣、肢体间空隙与投影仍使站姿清楚。截图 06 的深色前景支架、亮面上的人物与远处屋顶提供层次；支架的斜撑和底部结构具备连续轮廓。

借鉴：角色不必充满细节，但重心和剪影必须可读；结构有主次，遮挡随行进变化。画面的工业题材与压迫情绪不是本项目必须接受的设定。不能把几张静帧的观察当作已验证其完整镜头调度。

### Death Stranding：具体装备与连接的作用

官方环境背景以人物、近处石块、沿溪中景和远山形成距离，亮雾没有抹去全部线索。货物设备画面中，背负装备、身体站位、装置支承与操作位置可以互相解释。Chiral Bridge 画面的连接物对应一个真实岩体障碍，人物正沿其移动。

借鉴：装备说明身份；产物影响可达性和可用性。保留未知中的具体线索，让抵达带来新的观察。写实资产密度、载具体系、游戏独有设备和叙事不直接移植。

## 本项目的推荐方向（尚未确认）

推荐先评审 **A：高原边缘仍在使用的观测站**。与 **B：仍在运行的旧工业设施**、**C：流动勘测营地** 比较，A 能用一个具体场所容纳观察、行动、检查、局部恢复和新问题，情绪较开放，设施也有明确用途。B 的镜头和遮挡潜力较强，但容易走向压迫；C 的装备与部署动作明确，但容易增加资产种类与陈列感。

A 的初步任务：恢复一个远端记录器的数据回传，检查接头与供电，并保留对间断原因的新疑问。具体任务还需与工程内容核对，不能以遥测设备操作替代软件工程方法。

美术建议以风格化的可信形体、克制材质分区和明确主光为基础，先校准人物与设施的造型。Jusant 用于研究形体和使用痕迹，INSIDE 用于研究构图与轮廓，Death Stranding 用于研究装备与行动关系；不将三部作品画风机械拼接，不预定统一水彩、青色暗部、全局描边或“生态缸”切片。

### 人与 Agent 的设计提案

人：接近成人自然比例，外套、裤腿、鞋和随身设备有连续轮廓；先设计负重行进、俯身检查、停下观察三种姿态。近景要看出手和工具的接触，不再拿胶囊木偶作为造型候选。

Agent：先试一台能接近接口的低矮巡检车，轮组、工作臂、传感器具有用途；固定记录器属于环境设备。实体载体不等于完整 Agent 表达，任务范围、提交、证据、失败与人的裁决还需要状态和交互。传统模式同样可用自动化，不通过简单显隐车辆定义两种工程职责。

## 下一阶段的具体交付

先完成三个原创建构的关键画面：首屏总览、一次近景检查、边界停顿；另作同尺度的人／设备造型表。它们要解决书名留白、场景主体、身体重心、接触关系、设施用途与未知线索。当前研究板只给出这些画面的任务说明，并未伪称已完成概念图。

画面成立后，再深化一个行动片段。先验证“人物带着目的进入现场 → 产生候选 → 检查 → 局部改变 → 新的观察”，再扩展区域和模式。技术取舍按 [技术记录](./threejs-technical-review.md) 执行；材质试样与性能检查不能替代美术评审。

## 用户补充：环境包含气候

用户对研究方向表示“没问题感觉”，并提醒气候属于环境。该反馈支持继续深化当前研究，不意味着具体地理、季节、天气状态或角色资产已定稿。

环境设计需要关联三层：长期气候塑造地貌、植被、材料风化和建筑防护；当前天气决定云、风、降水与干湿状态；时间及光照决定阴影、空气透视与操作时的感受。不能仅在几何完成后叠加粒子，或把一张静帧中的雾直接解释为原作的长期气候。

观测站的建议片段：凉冷多风的高地，降水后间歇放晴的白天。建筑低矮且避主风口，入口与操作位有遮蔽，线缆和接口有固定及防护。植被低矮，具体生态待地点与季节校准。地表凹处局部湿润，檐下干湿不同；低云与雾主要位于盆地及山口，路径与近景保留清楚轮廓。云层、地表云影与光照变化应一致，草、衣摆和风向标共同表达风向。

三张关键画面使用同一个连贯天气片段：首屏的站房与远处云影、工作近景的遮蔽和干湿差异、边界停顿中增强的风感与低云间的具体线索。未知不依赖永久大雾，天气不直接决定工程检查通过。当前仅补充研究板和设计要求，未实现天气系统或修改三维场景。
