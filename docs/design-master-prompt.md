# 设计主提示词（Design Master Prompt）

本文件是本仓库**所有前端与视觉工作的唯一基准**。任何设计改动开始前先读它；与该文件冲突的实现一律视为缺陷。

---

## 一、专业场景定位与工作流认知

**产品形态**：一本中文技术书的在线阅读站，同时是可直接加载的 Agent Skills 发行物。
**读者**：写代码的工程师、技术负责人、以及把站点内容喂给本地 Agent 的使用者。
**他们来的目的**：确认"这本书值不值得读"，然后找到自己要的那一章。

因此**页面首先要可信，其次才要好看**。任何视觉效果若让人怀疑"这是一张宣传页还是一个技术仓库"，都判为失败。

**工作流铁律**

1. 先出**可打开的预览**（HTML/SVG/图），再写实现；预览未确认前不动线上站点。
2. 每个视觉决定都要能回答"少了它会丢什么"，答不出来就删掉。
3. 同一信息在页面上只出现一次。
4. 先测再交：给出实测数值（对比度、字节数、帧率、宽度），不接受"已实现"。

---

## 二、需求解析与信息架构设计

**首页信息优先级（不可调换）**

1. 这是什么（书名 + 一句话定位）
2. 凭什么可信（版本、许可、章节数、可下载制品）
3. 怎么开始（开始阅读 / 走进场景 / 安装命令）
4. 全书结构（10 章，唯一一次列举）
5. 给 Agent 的入口（llms.txt / llms-full.txt）

**禁止**：同一批章节在页面上出现两次；把内容藏在一次交互之后才可见；首屏与正文之间出现超过 80px 的无意义空白。

**阅读页结构**：左侧只放页面级导航（章），右侧只放当前页小节（h2/h3）；两者不得内容重复。

## 三、设计系统与视觉语言规范

**令牌优先**：字号、行高、间距、圆角、颜色一律走 CSS 变量（`--mt-*`），禁止在组件里写魔法数字。

**色彩**
- 中性冷灰阶为基底；**单一强调色**：信号橙（亮 `#b93a0a` / 暗 `#ff7a3d`）。
- 不引入第三个色相。语义块（公理/不变量/约束/反模式）是唯一例外，各有一色但同属低饱和。
- **禁止纯黑纯白**：正文 `#1f2328`/`#e6edf3`，背景取近白/近黑。

**线条**：装饰线一律 **1px**；焦点环 2px。禁止模糊阴影（`box-shadow` 带 blur），用 1px 细线与底色差异建立层次。

**字体**
- 正文：系统 UI 栈 + 中文字体优先级（PingFang SC / Microsoft YaHei / Noto Sans CJK SC），行高 1.85。
- 等宽：元信息、章号、表头、eyebrow 一律等宽 + `tabular-nums`。
- 显示字体仅用于拉丁字母与数字；中文标题靠**字号 + 字重 + 负字距**立气场，不依赖衬线。

**对比度**：正文 ≥4.5:1；大标题与其最差像素也须 ≥4.5:1；弱化文字 ≥4.5:1。计算后写入报告。

---

## 四、视觉层级与信息主次

- 每屏只允许**一个**视觉焦点。首屏焦点是场景或书名，不应两者同时抢。
- 正文列宽锁 **65–75ch**（当前 68.63ch），不改。
- 标题节奏：h2 上 2.4em / 下 0.8em；h3 上 1.9em / 下 0.6em。上间距必须明显大于下间距，让标题属于下文而非上文。
- 元信息（版本、日期、章号）在层级上必须比正文低一档，用等宽小字表达。

## 五、设计风格哲学

**一句话**：工程图纸的克制，加上一间**无人值守**的前哨。

**「迈向无人区」的双关是全部视觉的出发点，不是文案**

- 字面：未被测绘的地域、边境、旷野——人类尚未进场之处。
- 隐喻：Agent 在一线生产，人退到意图与裁决的位置——**人在物理上不在场，系统仍在运转**。

因此画面必须同时包含两件事，缺一不可：
1. **一小片已知**：室内被一束暖光照亮的一角。暖光不是温馨，是「人类已经点亮并定下规则的那一小块」。
2. **大片未知**：窗外深暗、无细节、无人类痕迹的旷野或虚空，越远越失去结构。不得把窗外画成风景名胜，未知必须是**没有特征**的。

**禁止的误读**：把场景做成温馨书房、咖啡馆一角、居家工位。任何一种「让人想坐下来喝杯东西」的氛围都判为失败——那是「有人」，不是「无人区」。椅子可以是空着并被推开的，机器可以还在跑，但**人不出现，且刚刚离开的痕迹要能被读出**。」

- 表现"技术感"靠**结构**（网格、发丝线、等宽元信息、编号），不靠发光与渐变堆砌。
- 表现"温度"靠**一束光**：全页允许且仅允许一处渐变——光源。其余一律纯色。
- 动画只为**解释状态变化**服务（进入、当前项、复制成功）。禁止无意义的漂浮与循环闪烁；所有动画在 `prefers-reduced-motion: reduce` 下停用。
- 密度优先于留白：宁可多给内容，不要用大留白冒充高级感。

## 六、配图、插画与品牌视觉

- 主视觉只允许两种形态：**内联 SVG**（几何/线稿）或**真实 3D 场景**（Three.js）。禁止概念图、禁止来路不明的位图、禁止 AI 图片直接当产品界面。
- 允许使用生成图作为**美术方向参考**（不直接上线），实现须在 Three.js 中按参考重做。
- 3D 场景规格：等距/长焦透视；唯一投影光为暖橙平行光（窗光），冷灰半球光补光；低多边形 `flatShading`；DPR ≤2（移动端 1.5）；阴影贴图 1024、单光源；draw call ≤40、三角面 <50k；页签隐藏即暂停渲染；canvas 就绪前先显示静态参考图（同时作为无 WebGL 的降级）。
- 章名不得烘焙进贴图作为唯一载体：贴图负责观感，可读文字用 DOM 叠加与 `aria-label` 承载。

---

## 七、复杂交互与数据呈现

- 表格：表头等宽大写 + 上下 1px 强线；行悬停淡底；数值列 `tabular-nums` 右对齐；窄屏横向滚动而非挤压列。
- 代码块：圆角、1px 边框、无阴影；终端命令用终端框并过滤提示符；复制成功需有可见反馈。
- 可交互元素：命中区 ≥24×24px；`:focus-visible` 2px 强调环；`Enter` 与 `Space` 等价触发。
- 全屏浮层：打开时锁背景滚动、焦点入内、Tab 循环、`Esc` 关闭、关闭后焦点与滚动位置还原。

## 八、行业参照与判据

参照对象（按可借用程度排序）：`vite.dev`（导航与信息密度）、`effect.website`（首屏与代码演示）、`hello-algo.com`（中文技术书的空间感）、`clig.dev`（纯字体的克制）。

**判据不是"像谁"，而是三条**：
1. 首屏 5 秒内能否看清：这是什么、凭什么可信、从哪里开始。
2. 把两张截图并排，我们的信息密度与层级是否明显弱于参照。
3. 关掉动画后，页面是否依然成立。

**每次交付必须附**：至少一组"我们 vs 参照"的并排截图，并逐条说明差距在哪、哪些已追平。

## 验收清单（每次设计交付逐项打勾）

- [ ] 首屏 5 秒测试通过
- [ ] 正文 65–75ch，未被本次改动挤压
- [ ] 明暗两套均无残留色，对比度实测 ≥4.5:1（含最差像素）
- [ ] 所有装饰线 1px，无模糊阴影
- [ ] 同一信息未在页面重复出现
- [ ] `prefers-reduced-motion` 下动画全停且画面完整
- [ ] 键盘可达：Tab 顺序合理、焦点可见、浮层可 `Esc` 退出
- [ ] 交付附带并排截图与实测数值

## 首屏机制：光 = 已知的边界（2026-10 定案）

首屏不是一张图，是一次**尚未完成的测绘**：绝对黑暗中一个不稳定的光源在扫，光扫到哪里，世界才在那里存在；光移开后缓慢退回未知。没有房间、飞船、屏幕、书等具体道具。

**刻线 = 充能，充满才可放行**

- 光照到石板时脊上刻线从根部向上生长；光移开缓慢衰减（衰减速率约为增长速率的四分之一）。
- charge = 1 才可点击进入该章；未满时点击只显示充能百分比。已充满者在光移开后**保持满亮**（已获授权不撤回）。
- 这一机制对应书中的「验证通过才放行」，是设计的一部分，不是加载动画。

**可达性底线（不可违反）**

- 真实章节链接始终在 DOM 中，可 Tab、可被索引，与 canvas 状态无关。
- prefers-reduced-motion 或无 WebGL：所有石板视为已充满，交互不受限。
- 必须提供键盘可达的替代路径，不允许「只能用鼠标且必须等充能」。

## 技术选型：为什么不用 R3F（附切换触发条件）

本站是 Astro + Starlight，首屏只有一个 3D 场景。R3F 的常规优势（水合、StrictMode、状态同步）在这里不成立，而代价是首屏负载约翻倍（React + fiber + drei + 后处理约 110 到 135KB gzip，叠加在 three 之上）。

**不采纳不等于不承认风险。** 以下三项任一失败，即切换到 React 岛 + R3F：

1. mount/destroy 连续三次后 renderer.info 的 geometries/textures 仍在增长（泄漏）
2. 窗口缩放后画面异常或相机错位
3. 存在 animation loop 冲突或重复渲染

验收时必须逐项报告，不接受「已处理」。
