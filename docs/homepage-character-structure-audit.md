2026-10-28。05、06 的完整动作未通过；06 已撤回“修正候选”推荐。没有已通过的行走资产。正式首页不接入这批动作，原画继续作为身份参照。

## 已复现的制作错误

1. **从原站姿到第一帧就改变了膝向。** 原姿态的双膝在各自髋踝连线的一侧，解算器却固定取画面左侧的另一解。第一帧骨盆只下移 0.3px，两膝便切换分支。脚点固定、骨长一致仍然可以产生明显错误的腿形。
2. **用错误位置的变形过渡掩盖缺失衣料。** 髋关节在源图 y=187/188，过渡却延至 y=220/229，把上大腿留给骨盆以免露缝。于是大腿中段出现假转折。将同一过渡稍向上移不能解决根因。
3. **完整姿态未被制作。** 既有输入是四分之三视角的站姿，隐藏裤料、两腿交会和脚掌滚动没有得到可信的绘制，仅从脚点与投影骨长推算动作。局部衣褶无法补救整条腿的形体。
4. **验收顺序颠倒。** 导出可复现、脚点与握点稳定只能说明相应技术约束；前面的交付却把这些作为继续推进的依据，没有先挡住完整人物的视觉缺陷。

## 内部对照结果

`scripts/audit-actor-rest-transition.py` 打开保存的 06 工程，比较源姿态、第一帧及相同脚点下的另一个 IK 分支，内部输出位于 `.lab/actor-structure-audit/`，不进入页面或正式图集。

第一帧恢复源膝向可以缓解站姿扭曲，但同一规则用于经过姿态又会出现反向弯腿，髋腿轮廓和交会也仍然失败。两组都拒用。该对照证明错误可复现，不证明另一分支是一套合格步态，也不能推出所有二维骨架方法都不可行。

渲染时必须暂时移除已采样动作的驱动，防止渲染重新求值覆盖手工诊断姿态；输出后核对实际膝点。诊断保留源规格与骨架文件摘要，不修改源工程。

## 接下来的制作边界

停止对 05/06 追加局部补丁、过渡帧或其他朝向。下一次制作从同一原画身份下的完整承重、经过、落脚姿态开始，同时处理髋膝踝、躯干、手持物与遮挡；隐藏衣料在可编辑母版中补足。关键姿态先单独成立，再决定骨架可以插值哪些部分、哪些部分需要姿态专用绘制。

出样前自行检查：完整轮廓、膝向与大腿连续性、前后腿关系、握持、接地；然后看相邻姿态和连续动作。技术约束另列，不能抵消任何视觉失败。失败试验可以保留复盘，但不再作为“最新修正”交给用户验收。

## 已提炼进通用 skill 的约束

- 判断顺序改为完整姿态、连续动作、场景扩展；工程检查不能替代任何一项视觉判断。
- 每次试验同时检查预期改善与完整人物的副作用，局部改善不等于修正成立。
- 同类缺陷在局部调整之间反复转移时，停止扩展当前试验，重新判断输入和制作方法。
- 区分内部试验、自行检查与用户认可，失败试验撤回推荐；不让用户承担第一轮基础质量检查。
- 诊断图必须验证实际求值和输出，防止动画重新求值覆盖临时修改，形成没有实际差异的伪对照。
