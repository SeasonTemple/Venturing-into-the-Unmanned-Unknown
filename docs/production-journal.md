2026-10-27。用户要求先提交当前场景草稿、合并主分支，并明确确认将已选阅读样张接入正式站点。实际主分支为 `main`。阶段快照 `2c2cc39` 与远端新增内容合并为 `efcc088`，已推送；正式首页的场景没有替换为独立候选。

## 实现

- Starlight 继续提供构建期原文、章节 URL、元数据、Pagefind 和 Expressive Code。`JournalFrame`、`JournalColumns` 和 `JournalContent` 只对十章生效，其他路由仍使用默认组件。正文不再等待浏览器请求整章 HTML；关闭 JavaScript 仍保留完整文章、SVG、章节目录与下一章链接。
- 接入已确认材质研究中的实体山脊、受光阴影及未知侧断线。移动端独立裁切；10Hz 上限、缓存静态阴影，离屏、后台和专注阅读暂停，减少动态偏好下静止。Three.js 与表面模块动态加载，失败保留 SVG。
- 正文使用清晰 DOM；缓慢移动的测绘底图在表层下以深度、折射和模糊采样呈现。进入正文后才初始化该 WebGL 背景，未成功时回退至二维底图。浅色表面覆盖进一步降低底图对正文的干扰；深色主题使用单独遮罩。
- 左侧是几个阅读阶段，全部小节收进页边目录。上下按钮分别回到正文开头与章节底部；全书目录按需打开。320px 手机上阅读工具分成两行。专注阅读收起页头、背景和批注。
- 《验证》的批注与图版按标题主题定位，适应合并后新增的“形式化验证”小节。新增阅读辅助不混入 Markdown 复制或原文完整性比较。人提供意图和 HITL 裁决的最新章节表述保留。
- 已选预览的视觉文件作为生产基线复制至 `site/src/scripts/journal/` 和 `site/src/styles/journal/`，生产构建不依赖预览服务器或 `/deps/` 路径。预览文件保留为设计历史，后续正式阅读页修改以生产文件为准。

## 边界

全书沿用一套地形材质，各章使用不同标题、主题与阅读路线；仅《验证》包含针对原文的交互图版和批注。表层透射是屏幕空间近似，不是物理介质模拟。当前改动更新正式阅读页，不表示首页场景设计已验收。
