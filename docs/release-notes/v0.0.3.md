# v0.0.3 — 方法论内容刷新：可执行规格、多语言验证、DST / Expect、Agent 审阅纪律

## 变更章节

- 第 0 章 导论（`skills/ai-native-sdlc-introduction`）：明确「放大理解而非不写不读代码」；补充可执行规格、快速可读反馈、可理解性目标与适用边界。
- 第 1 章 意图与需求（`skills/ai-native-sdlc-intent-requirements`）：验收可执行化（表格/属性线索）、正反例消歧、向验证/测试/仿真的映射。
- 第 2 章 设计与架构（`skills/ai-native-sdlc-design-architecture`）：非法状态不可表示；类型/模型作全局不变量；可插拔时间/IO 边界以支持确定性仿真。
- 第 3 章 验证（`skills/ai-native-sdlc-verification`）：分层模型强化；规格歧义与 Agent 冲突缓解；**多语言**实现层工具对照（Rust/C/Ada/Go 等）与按风险选型；技术中立。
- 第 4 章 实现（`skills/ai-native-sdlc-implementation`）：为验证/Expect/仿真留钩子；可读可审优先；禁止删测试换绿灯。
- 第 5 章 测试与质量保障（`skills/ai-native-sdlc-testing-quality`）：属性/模糊/差异/变异；**Expect 测试**；**库级与全系统确定性仿真测试（DST）**；与混沌分工；跨语言表述。
- 第 6 章 集成与交付（`skills/ai-native-sdlc-integration-delivery`）：门禁含属性/仿真种子回归；Agent 大 PR 合入纪律。
- 第 7 章 持续演进（`skills/ai-native-sdlc-continuous-evolution`）：人机 code review 纪律；理解型审阅 vs 自动气味扫描；reward hacking 防范。
- 第 8 章 工具与技能生态（`skills/ai-native-sdlc-tools-skills-ecosystem`）：验证/测试/DST 分层最小集；重型工具按风险启用；多语言选型提示。
- 附录（`skills/ai-native-sdlc-appendix`）：术语表扩充（DST、Expect、可执行规格、各语言验证工具等）；反模式与总清单对齐。
- 清单（`checklists/master-checklist.md`）：与附录及各章门禁同步。
- 站点文案：`README.md` 原则与版本说明；`book.config.json` / `CITATION.cff` 版本升至 v0.0.3。首页章节摘要仍由 `site` 构建脚本从各章 `SKILL.md` 生成，随正文自动更新。
