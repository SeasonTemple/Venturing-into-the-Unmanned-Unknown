# v0.0.2 — 在线阅读站上线：中文全文搜索、页面动作与 Agent 入口

## 变更章节

本轮不改动章节正文，十章的文本与 v0.0.1 逐字节一致（站点构建时用 `verify-content.mjs` 校验）。

- 全部章节（`skills/*`）：正文零改写，仅新增在线阅读形态。

## 站点与工程

- **底座从 mdBook 迁移到 Astro Starlight**。唯一决定性理由：mdBook 的 elasticlunr 不索引中文词条，搜索「验证」返回 0 条；Pagefind 返回 11 条并带高亮摘录。
- 页面动作：复制本页 Markdown（构建期内联原文，不暴露 `.md` 路由）、回到顶部。
- 新增 `/llms.txt` 与 `/llms-full.txt`，供本地 Agent 直接读取。
- 自托管三款 Latin 子集字体（OFL 1.1，已声明于 `THIRD_PARTY_NOTICES.md`）；中文回退系统字体。
- 语义块样式（公理 / 不变量 / 约束 / 反模式）已就绪，正文尚未启用。
- `validate-skills.yml` 保留版本一致性闸；`link-check` 不再检查站点自身 live URL（由 `pages.yml` 的产物校验覆盖），消除部署竞态。
