# 脚部接触与重定向方法复核 · 2026-10-29

这一轮不发布新的动作版本。`actor-fk-reference-v02` 的工程检查通过了膝、肘、肢段长度和保存重渲染，但完整人物审看没有通过：支撑脚的鞋底发生明显侧倾，鞋沿先接地而大部分鞋底悬空。此前把“最低顶点接近地面”当成接触成立，是错误的验收指标。

## 已确认的缺陷

- 第 48 帧（源帧 236）左脚是支撑脚。实际求值的左鞋底拟合平面约偏离水平 **26.4°**；底面样本高度约 **−1.63 至 +46.64 mm**，平均约 **24.0 mm**。最低点约 −2.7 mm 不能证明鞋底贴地。
- 右脚在该帧是摆动脚，底面约偏离水平 **18.3°**，高度约 **+32.2 至 +72.9 mm**；抬脚本身不是问题，不能用摆动脚离地来替代对支撑脚的判断。
- 脚和脚趾仍直接复制来源世界旋转，没有像手臂、腿段那样建立目标模型的足部静止坐标系。鞋底侧倾很可能来自来源足部坐标与目标鞋／脚趾骨架的坐标不一致，但在分离鞋网格、权重和来源轴向之前，不把它写成已证实的单一根因。

## 为什么当前方法不能继续小修

`CalibratedFK` 同时证明了“关节曲线可复现”和“实际脚部接触不成立”。这两个结果并不矛盾：关节角、最低顶点、固定地面和重渲染一致，都不能证明鞋底平面、承重转换、脚跟—前掌滚动及鞋网格变形正确。继续只调一个脚角度，可能把错误从脚踝移到膝、髋或另一只脚。

## 下一条验证路线

1. **先做足部静止校准，不进动作成片。** 在目标绑定中单独显示脚、踝、球、趾和鞋底接触面；记录每个部件的轴向、原点、镜像侧和有效权重。用一个中立站姿让两只鞋的整块接触面同时成立。
2. **只取四个支撑关键姿态**：脚跟着地、全脚支撑、前掌承重、趾离地。每个姿态同时看正面、侧面、俯视和实际鞋网格；验收接触面、踝—膝方向、鞋底法线和重心投影，不能只看骨架或最低点。
3. **再比较两种管线**：
   - 保留 FK：足部使用校准后的局部轴和受限的脚跟—前掌—趾滚动，明确记录对来源动作的改变；
   - 改用二维逐帧／姿态绘制：只制作上述四个关键姿态，验证像素轮廓和接触是否能稳定成立。
   两条路线使用同一套关键姿态验收表，哪条先通过才扩展到循环、转身和网页接入。
4. **通过完整关键姿态后**，才接入负重、装备和环境遮挡；MMX／视频生成只作为动作参考，不作为脚部解剖或接触的自动解法。

当前结论是：问题暴露了本次足部映射和验收方法的不足，尚不足以否定三维预渲染或二维制作本身；但 `hands02` 不能作为可靠的动作基线，也不应继续在它上面叠加补丁。

## 简单相对脚轴试验的结果

随后制作了独立的 `fk-foot02` 对照：脚和脚趾改为“来源当前旋转相对来源首帧静止旋转，再套目标脚部静止姿态”。膝、肘和保存重渲染仍然通过，但第 48 帧左鞋底侧倾约 **28.3°**，鞋底最低点约 **+16.8 mm**，整段固定地面残差扩大到约 **−21～+20.8 mm**。因此，单纯替换旋转参考系没有解决支撑问题，实验已撤回。下一次若继续三维路线，必须同时重建足部几何轴、鞋与脚趾权重及脚跟—前掌—趾的支撑滚动；不能再只改矩阵。


## 二维过渡试验的接触锁问题

在四姿态二维样本上尝试 `full-support → passing → contact` 两段过渡时，第 21 帧左脚滚动触发现有接触断言。当前实现把一个脚跟／趾锚点同时当作整只鞋的最低边界，导致锚点调整会连同鞋整体移动，无法表达前掌承重和趾离地。该试验已撤回；下一次二维过渡必须把脚跟、前掌和趾作为独立接触面记录，再检查全身轮廓。


## 姿态连续性隔离试验

固定根位移、暂时移除路径脚锁后，四姿态之间的端点插值仍在第 13–21 帧造成腿部交叉和不可信的换重。由此确认问题不只是接触锚点：腿部轮廓不能从两个端点按数学曲线自动补齐。下一轮需为换重过程增加人工中间关键姿态，再决定哪些区间可以插值。

## 关键姿态复核与整姿态修绘入口

随后 `raster08` 虽导出八张参数姿态，原审核图仍只显示前三张且标题错配；完整复核确认经过、落地与换重仍有剪刀状腿形，未制作新动画。新四阶段控制底稿已改善明显交叉，但仍是原画衣料取样和刚体上身，不能作为脚部支撑四相位或自然负重验收。

本次同时发现旧修绘器强制保留 alpha，无法修正错误的鞋底或膝轮廓。新整姿态 ORA 回导允许实际重画轮廓，并验证修改可以保留、重开再导出且不会影响其他姿态。它修复制作能力缺口，没有自动补全接地与人体美术；详见 [整姿态画稿管线](homepage-character-pose-paint-pipeline.md)。
