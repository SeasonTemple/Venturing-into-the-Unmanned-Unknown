# 阅读体验修正（2026-10-27）

本次覆盖代码可读性、阅读导航、夜间模式、搜索、站点图标、手机页头与环境动态；保留已认可的像素原野首页和地形材质。

- 代码块按主题选用浅灰绿／深青底，正文中的行内代码与代码块分开设字号。桌面代码实测 14.4px，手机 14px；保留 Expressive Code 的语法配色、行标记和复制功能。
- 构建强制刷新 Astro 内容缓存，避免 Markdown 中的高亮样式哈希指向上一次构建的文件。发布前逐一检查 HTML 引用的本地 CSS、JS、图片和字体确实存在。
- 桌面阅读改为左侧全书十章、中间约 72ch 原文、右侧本章全部小节。右侧随阅读位置展示已有作者辅助批注或本节真实三级标题，不生成填充性批注。中等屏幕收起右栏，窄屏由目录弹窗承接；原有批注在对应小节后显示。
- 页头工具下面增加常驻的相邻章节导航。其定位跟随实际工具栏高度，避免手机因边框或字号差异发生重叠。页底保留完整章节名称；页边向上按钮仍回正文开头。
- 夜间配色统一正文、代码、导航和搜索表面，并同步浏览器原生控件的 color-scheme。章首仍沿用已认可的深色地形。
- 目录抽屉规则限定于 `#navigation`。搜索恢复为居中的独立弹窗，输入和结果使用当前主题的底、文字和强调色，保留焦点、Escape、检索索引和暂停环境动态行为。
- 新 favicon 是代码绘制的矢量图形：深青底、分面山脊、暖色测绘路线和光点。另提供 180px 触屏图标；无外部生成用量。
- 手机页头使用真实平面等高线和每章独立路线，不再展示透视地形。等高线从共享高度场离线抽样；节点和图例仍指向本章真实小节。响应式图片源保证手机不下载桌面地形底图。
- 首页云层改为连续有界运动，修复原先指数公式收敛停住的问题；增强选定草簇与水面变化。仍为单次 WebGL 绘制、两张纹理、最高 24fps；人物和建筑不参与位移。手机首页保持静态。
- 阅读页的未测绘边界增加分段漂移和断线流动，手机平面边界也有断线变化。山体本身仍是共享静态图，不宣称动态三维光照。页头和正文各自按可见性暂停，并响应统一开关、搜索、后台、专注和减少动态效果设置。

原先悬浮圆圈改成黄铜测绘桩。离线重建原地形三角网，用相机射线确认可见表面，投影测绘桩的分面、接触阴影、落地刻线和与光向一致的短阴影；路径沿地形三角面采样，并剔除被山体遮挡的片段。文字标注移到山体外缘，以细引线对应测点。

运行 `node site/scripts/build-survey-overlays.mjs` 可重建坐标。Three.js 仅用于离线生成；正式阅读页仍不加载 Three.js、不创建 WebGL 上下文。各章共用一张地形底图，路线、测点和语义各自独立。

使用既有拥有独立 profile 的 Chrome 检查器，测试所有十章的原文、节点与键盘跳转、目录、代码复制、真实搜索结果、明暗主题、320–2560px 布局、页头与正文暂停、无 JavaScript 及无 WebGL 降级。新增测试直接检查 DOM、布局、实际字体和颜色对比度；首页通过 WebGL 像素读取比较 0/2 秒与 80/82 秒的环境区域，同时确认固定区域没有变化。

所有十章 Markdown 继续与源文逐字节校验。现有视频未接入角色行走；本轮没有新增图像／视频 API 调用。

## 页头状态与嵌套滚动修正

后续用户截图指出章首翻章栏仍为白色，目录右侧又出现滚动条。前者是深色状态规则优先级低于生产默认样式，导致背景与文字分属两种配色；后者来自右栏的最大高度与 `overflow:auto`，并非滚动条缺少样式。

工具栏与翻章栏现在共用同等优先级的配色规则，在章首统一深青，进入正文后同步用320ms切换到当前阅读配色；初始章首状态提前建立，避免先出现白栏。下一章入口靠右对齐。页面滚动条延续原有样式，补齐章首与夜间的轨道配色。

左右目录移除内部滚动区域。ResizeObserver根据实际栏高和可用视口决定短栏吸附、长栏随文档自然滚动；动态批注改变高度时同样重算。滚轮在目录上操作直接滚动文档，表格、代码和搜索的必要溢出滚动保留。

章节间使用浏览器原生跨文档 View Transition 淡入淡出，继续完整页面导航，不恢复曾影响搜索初始化的客户端路由。不支持的浏览器使用正常导航；减少动态效果时停用新增过渡。

扩展后98项阅读检查全部通过，控制台错误和测试浏览器残留均为0。新增实际采样章首／过渡中／正文两层栏位的颜色，检查长栏没有内滚动区域、在目录上的真实滚轮事件滚动文档，以及点击下一章确实产生原生跨文档过渡。

## 主题焦点与翻章抵达

用户指出主题选择器的粗橙框不协调。保留原生可访问的主题选择器，将该控件焦点提示改为工具栏内的一像素细线；强制颜色模式仍保留系统焦点线，不移除其他控件的键盘指示。

上下章链接现在携带一次性的会话抵达意图，URL与正常浏览历史保持不变。目标章绘制后先展示页头约一秒，再平滑滚入正文并将键盘阅读焦点放到文章。顶栏与页尾的翻章入口行为一致，首末章的首页链接不触发正文流程。

手动滚轮、触摸、点击或键盘操作会取消自动抵达；自动移动进行中也能立即打断。隐藏标签页不消耗展示时间，翻页离开时清理等待。直接访问、带小节锚点、刷新和历史返回不重播流程；系统减少动态效果时保留短暂页头展示，之后直接定位正文。

扩展后108项阅读检查通过，控制台错误和测试浏览器残留均为0。覆盖细线焦点、顶栏下一章和页尾上一章的停留与抵达、手动滚轮取消、直接访问、锚点、刷新及减少动态效果；例测正文定位在工具栏下方24px，取消后保留用户自行滚动的120px位置。
