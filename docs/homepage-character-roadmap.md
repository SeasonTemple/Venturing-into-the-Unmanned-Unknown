# 首页人物制作路线与闸门

## 唯一目标（持续推进到完成）

让访客在首页完成一段可信的原野探索：进入观测站、沿限定维护路主动行走、在停点收步并转身回望，人物的朝向、脚底接触、重心、装备和像素尺度始终连续。第一段样片通过后，再把同一套状态接入正式首页；在此之前不扩展新天气、新视频或新的角色制作路线。

**完成定义：**

- 四向身份源和正面→侧面转身帧可追溯；
- 左向 8–12 帧完整像素行走在原生尺寸、场景尺寸和窄屏下都能读出接触、抬脚、前摆、承重和上身响应；
- 独立路线原型支持手动移动、停步、停点点击、转身，以及自动行进被手动输入接管；
- 减少动态、失焦、离屏和连续运行不会持续增加帧序、资源或内存；
- 右向移动只有在另行手绘并通过右向资产闸门后才加入，不用镜像或倒退伪装。

**当前唯一闸门：** `pixel-walk-v01` 的原生尺寸视觉复核。行为壳与预览入口已经通过自动检查，但正式首页暂不显示这套角色；人物的比例、轮廓、动作自然度和场景尺度仍需人工通过后才接入。右向行走若以后需要，必须另行手绘并通过同一套源资产闸门，不用镜像补齐。

这份路线把当前工作从“不断试图改善观感”收敛成四个有明确退出条件的阶段。每个阶段只交付一个可检查结果；未通过就回到该阶段修源，不扩展帧数、方向或首页交互。

## 已通过阶段：像素身份源

**目的：** 让正面、侧面、背侧、背面四套原画成为同一个可追溯的像素源，并建立前视图的可编辑边界。

**已交付：** `pixel-native-master-v01`，包含原画锁定层、前视图分层、四向参照、方向契约、像素一致性检查和[阶段报告](../prototypes/visual-direction/pixel-native-master-v01/stage-report.json)。

**通过条件：**

- 原生尺寸下四向都能读成同一个人；
- 关闭锁定底图后，前视图仍能逐像素复原；
- 工具箱、记录器、衣摆、双脚和基线有明确归属；
- 被遮挡的手指、袖内和转身中间结构明确列为未知，不用三维渲染填空。

这一道闸门按“源契约通过”收口；它不等于人物美术或动作通过。当前只剩轮廓清理和必要的隐藏区域补绘。通过前不制作行走。

## 阶段二：一个真实转身（已通过）

**目的：** 用像素原生帧完成一次停步转身，验证方向变化时人物身份和装备关系不丢失。

**当前小样的作用：** `pixel-turn-proof-v01` 保留为早期载入记录；正式转身使用 `pixel-turn-keyframes-v01` 的手绘完整中间帧。

**当前交付：** `pixel-turn-keyframes-v01`，包含正面、3 张中间手绘完整帧和侧面端点，以及原生尺寸、3× 对照图、OpenRaster 源和人工复核记录。转身源与正式首页播放均已通过。

**复核结论：** 阶段二确认头颈、肩胯、脚底和装备归属连续；端点与中间帧的色簇密度差异保留为观察项，不阻塞当前左向路线。

**通过条件：**

- 头、胸廓、骨盆和脚底在转向中保持连续；
- 人物朝向与移动意图一致；
- 工具箱和记录器随所属手臂转动，手掌方向可读；
- 3 倍放大检查没有撕裂，原生尺寸轮廓仍然成立。

如果三个中间帧无法成立，停止动作制作，回到阶段一补绘源层。

## 阶段三：四个负重关键姿态（已通过）

**目的：** 在一个已经通过的方向上验证完整身体动作，而不是只动腿。

**当前交付：** `pixel-loaded-keyposes-v01`，包含右腿承重、左腿前摆、左脚跟落地、左腿承重四张完整帧，原生尺寸与 3× 对照图、OpenRaster 源、检查器和人工验收记录。四帧已作为 8 帧行走的上身与承重锚点。

固定四帧：右腿承重、左腿前摆、左脚跟落地、换到左腿承重。每帧同时检查骨盆、胸廓、肩、肘、头、两件装备和支撑脚。

**通过条件：**

- 重心随支撑脚变化，膝盖没有内凹或反向折角；
- 上身不是冻结层，肩肘和器物对承重有响应；
- 手掌、袖口与装备接触在每帧可解释；
- 四帧放在同一张原生尺寸对照图中仍像同一个人。

未通过时只修关键帧源层，不生成中间循环。

## 阶段四：短行走与首页接入（视觉闸门未通过）

阶段三通过后，四个关键姿态已扩成 8 帧左向短行走，并接入停步、上一测点移动和转身。移动任务与转身任务各自使用独立时间基准，按钮状态在贴图加载和任务完成时同步更新。行为预览入口通过自动检查，但正式首页已用 `actorPreview=1` 闸门隔离，避免把粗糙源当成产品视觉。

**当前交付：** `pixel-walk-v01`，包含 8 张左向完整像素帧、原生尺寸与 3× 对照图、OpenRaster 源、上身响应诊断、检查器和人工验收记录；`pixel-route-v01` 已通过独立行为、十分钟压力与预览入口检查。正式首页暂不显示角色，`pixel-route-v01/home-checks.json` 只作为预览证据。

**首页接入条件：** 先通过原生尺寸静帧的比例、轮廓、重心、装备接触和可读性复核，再验证场景尺度、窄屏、长时间运行与正式首页移动。当前只完成行为预览，不满足正式接入条件。

后续若扩展方向，只允许在当前样片稳定后另开资产闸门；三维 v03、转身小样和未通过帧不回流到正式首页，也不追加 MMX、Tripo 或视频生成调用。每个扩展阶段都要有独立的源、行为和性能证据，避免用工具数量代替视觉验收。
