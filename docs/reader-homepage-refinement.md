# 阅读页与手机首页修正 · 2026-10-27

用户指出正式阅读页共用无节点的地形、卡顿、两套页尾、复制入口位置，以及手机首页没有铺满、人物朝向不随路线变化和白底测点标签。

## 测绘页头和阅读性能

旧实现确实共用 `createRelief`，但生产 `mountRelief` 没有使用传入的章节配置。页头每次导航重新建立地形、噪声纹理、环境预过滤和阴影；进入正文时再建立第二个全屏透射渲染器。已有离屏暂停和限帧，仍无法消除这些初始化开销。

保留原有材质的光照和形体，离线导出共享地形与描图膜，转换为 WebP。正式阅读不再导入 Three.js，也不请求 WebGL 上下文。每章路线、节点和未解边界由 `ChapterSurvey` 根据真实章节配置输出为 SVG 和链接；三处节点按主题指向实际小节。光照是材质的照明，不代表验证覆盖或阅读进度。

描图膜保留同一底图和层次，运行时只做下层图像的缓慢合成位移，表层与文字静止。系统减少动态、用户暂停、离屏、后台、搜索和专注阅读都会停止位移。两张图片合计 64,766 字节，可跨章节缓存；运行时不再计算噪声高度场、阴影或每像素21次透射采样。

使用 `node prototypes/visual-direction/browser-check.mjs --reader-audit`，同一 Chrome、1440×960／390×844、4倍 CPU 降速、禁用网络缓存，记录真实脚本字节、长任务及上下文请求；报告在 `.lab/reader-revision/`，不是实际移动设备帧率承诺。基线脚本728,243字节，修改后155,579字节；上下文请求由4次（预检测与构建器各请求一次，共2个实例）降为0。

`--profile-reader` 的CPU采样还定位了旧全站滚动更新器与新手记更新器的重复布局。阅读页现只保留自己的滚动／目录生命周期，并在修改导航class之前集中读取位置；代码块复制反馈仍保留。远处正文小节使用 `content-visibility:auto` 延后布局，完整源文仍在DOM中，浏览器原生查找、焦点及章节节点会揭示目标段落；打印不启用此优化。

同条件基线／最终：桌面长任务累计4267→862ms、最慢1389→862ms；390px累计1484→221ms、最慢358→221ms。均为上述4倍CPU降速的本机采样，包含初次样式布局，不等于真实设备延迟保证。最终不再常驻三维帧循环，也没有正文透射渲染器。

资产来自 `prototypes/visual-direction/journal-assets.html` 与已有材质。通过统一截图入口导出，确认帧已实际完成着色，再运行 `node site/scripts/build-reader-assets.mjs` 压缩；制作时间、尺寸和来源另存 `site/public/journal/sources.json`。没有采用生成图片代替地形原设计。

## 结构与排版

- `Footer` 在章节页不再渲染默认翻页、默认更新栏和居中的爬虫链接，避免与 `JournalFrame` 重复。
- 手记页尾只有一组相邻章节；细线、编号、字号和留白服从手记。机器可读文件保留为次级“文本索引”。
- Markdown复制移到正文前的工具行；原文仍来自构建期嵌入的完整源文本，保留真实剪贴板检查。
- 回到正文开头只留页边栏；无JavaScript仍可读完整正文与相邻章节。
- 手机首页使用100svh场景底图和天空上的标题，静态人物与观测站保留在竖幅裁切内；只提供开始阅读和章节入口，不启动环境WebGL或加载角色动作。

## 人物朝向与视频

现有动作图集是原画正面拆件，不能表达前往左后方的背面，不能用镜像或手脚摆动冒充转身。正式首页先保留原画人物站姿、环境动态与记录查阅，撤下错误朝向的位移；原型动作仍在研究目录可复查。这不是已完成多方向人物。

已通过现有mmx本机入口、OAuth登录尝试 `MiniMax-Hailuo-2.3` 图生视频，目标为转身、左前方步态、左后方步态的固定镜头样片。接口返回：`当前已达到 Token Plan 用量上限。为避免调用中断，请升级 Token Plan 套餐，或购买积分补充用量并开启积分自动消耗。` 没有返回视频或任务ID，未再次付费提交。H3另需合适的按量API Key，未擅自切换凭证。

后续素材验收需覆盖完整转身、方向与路径一致、脚底承重、髋肩与头部协调、装备左右手不变、像素尺度与原画统一。选定有效循环后才抽帧、清理背景与轮廓、对齐足底并打包方向图集。视频不能直接当作已经合格的逐帧动作。提示词保存在 `prototypes/visual-direction/meadow-prompts/directional-video-v01.txt`。

测点的白框调试式标签已撤去；只在记录打开时显示一个贴地细环，地点与事件用手记栏表达。

## 验证与收尾

运行构建、源文逐字节校验、正式阅读检查、首页检查和上述性能审计。功能覆盖十章独立路线、真实节点定位、正文复制、单一页尾、暗色导航、320—2560px布局、手机完整首屏、搜索、减少动态、无JS和无WebGL。浏览器截图本次共6张，包含两种材质导出、一次未通过材质检查的导出以及三张页面复核；均走统一 `scripts/shot.mjs --batch`，没有增加其他截图入口。所有Chrome使用独有profile，在finally按PID树结束并删除profile，各次报告残留0。
