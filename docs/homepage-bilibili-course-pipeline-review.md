## 对本站管线的实际调整

### 1. 区分制作路径和共同工序

制作前段保持两个明确候选：

- **完整帧路径**：同一人物参考与姿态约束，制作完整关键帧，再逐帧精修。
- **分层路径**：合格完整人物分层，补齐遮挡部位，绑定／约束后以动作参考驱动，再离线烘焙和精修。

两条路径都接入共同工序：**保留原始文件 → 只读诊断 → 可回改编辑 → 角色根节点与固定画布对齐 → 动作清单／帧图集 → 实际尺寸与洋葱皮检查 → 场景运行验证**。

PixelLab、MMX、其他编辑器或生成器属于前段可替换工具；是否采用由实际所需控制与小样结果决定。建立管线不以开通新服务为默认前提，也不因生成器不可用就用程序人体替代美术母版。

### 2. 保留不可替代的编辑阶段

母版和动作可以在同一小样中迭代，不要求先做出一张无法回改的“完美立绘”。但必须有真实可编辑输入和产出；洋葱皮、蒙版、关节与握点是制作依据。将未见部位、关节露缝或衣服体积交给无依据的拉伸／填色，仍会重现此前问题。

生成、补绘、绑定、修帧分别记录使用的实际工具、输入、参数、结果与失败。不能把提示词、示意帧或空文件夹称为整条链已实现。

### 3. 对齐以人物根节点和脚点为准

统一画布和动作的共同裁切范围；记录角色根节点、足底基准、握点和真实姿态。不要为了每帧包围盒底部一致而消除正常重心起伏，也不要让工具箱的摆动改变整个人物的裁切中心。

世界位置、动作中的足点和实际步长共同决定滑步；`bottom-center` 或 `union` 都不能单独保证走路接地。固定脚、离地脚和身体起伏分开检查。

### 4. 保持本站画风与非对称身份

- 不照搬 32 × 32、Endesga 32 或单角色不超过 12 色的横版示例规格；以本站画面、人物细节和目标显示尺寸制定自己的规格。
- 不将所有半透明像素或调色板外颜色一律清零：先区分边缘污染、真实透明物件、源画面特征与最终渲染需求。
- 不将“向右静帧＋向左镜像”的示例用于本站人物；右手银箱、左手记录器的归属和不同方向的光照都需要真实检查。
- 不把统一调色板、相同帧尺寸或不重复颜色数量等同于美术通过。
- 原图 156 × 348 保留；78 × 174 是旧制作中的缩小参照，尚无证据将其视为原画原生像素尺寸。

## 下一次制作应怎样验收

验收对象是可重建的制作工程：真实母版与编辑源、少量完整姿态、绑定或姿态约束、导出清单及检查结果。至少能改动一个姿态并重新导出，无须从另一张生成图重新拼人物。

当前已有播放器、固定画布与图集试验；人物母版、隐藏部位与动作自然度仍未达到要求。借鉴该合集能改善生产组织，不能消除这些实际缺口。下一阶段继续验证前段人物生产与编辑，而不是再扩大动作数量或只重写拼表工具。
