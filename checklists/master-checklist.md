# AI-Native SDLC 总检查清单

与附录及各章门禁对齐。顺序：意图 → 设计 → 实现 → 验证 → 测试 → 交付 → 演进 → 工具。

## 意图与需求
- [ ] 目标可观察
- [ ] 边界与非目标清晰
- [ ] 当前基线内验收可判定
- [ ] 关键验收有表格或属性线索
- [ ] 重要已知未知已标明
- [ ] 关键歧义已消除
- [ ] 高风险线索已标记

## 设计与架构
- [ ] 模块职责清晰
- [ ] 关键接口有契约
- [ ] 关键非法状态尽量不可表示或入口校验
- [ ] 高风险路径标明验证/测试/仿真去向
- [ ] 失败与恢复策略已定义
- [ ] 非确定性依赖边界清晰
- [ ] 重要决策已记录

## 实现
- [ ] 代码落在既定边界内
- [ ] 接口行为符合契约
- [ ] 失败路径显式
- [ ] 高风险路径保留可检查性
- [ ] 无未批准架构级偏差
- [ ] 关键逻辑对 HITL 可读

## 验证（正确性层）
- [ ] 关键性质有 ID 与陈述
- [ ] 通过项填写已查性质与未覆盖
- [ ] 高风险设计检查完成或显式签核跳过
- [ ] 实现层检查按语言选型完成
- [ ] 证据可重放
- [ ] 反例已关闭或已回流
- [ ] （若引入形式化）D1–D6 已记录；维护 owner 明确；未把调研当实施令

## 测试与质量保障（正确性层）
- [ ] 主验收有自动测试且映射性质 ID
- [ ] 关键失败路径有覆盖
- [ ] 关键性质有 PBT 或等价手段
- [ ] 合并相关绿灯可汇总未覆盖说明
- [ ] 高风险输入面有 fuzz 或等价（如适用）
- [ ] 关键协作有 Expect 或库级仿真
- [ ] 分布式/恢复已评估 DST 或接受风险
- [ ] CI 可执行；证据可取回
- [ ] （建议）关键区差异或变异抽检
- [ ] 实现-测试同源时有独立性措施或风险记录

## 集成与交付
- [ ] 自动检查通过
- [ ] 性质覆盖表齐全
- [ ] 关键回归未无故跳过
- [ ] 制品可追溯；回滚可用
- [ ] 发布可审计
- [ ] 风险发布已经 HITL 或书面策略
- [ ] 变更粒度可审

## 持续演进
- [ ] 信号采集与分级
- [ ] 问题回流到正确层级
- [ ] 修复附带回归（含种子/轨迹若适用）
- [ ] 资产与行为同步
- [ ] 复盘结论写入规则/Skill/门禁

## 工具与技能生态
- [ ] 关键环节有最小自动能力
- [ ] 核心 Skill 可触发
- [ ] CI 与本地路径一致
- [ ] 重型手段按风险启用（先 D1–D6）
- [ ] 写作检查器非硬依赖
