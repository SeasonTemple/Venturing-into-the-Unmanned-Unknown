# AI-Native SDLC 总检查清单

与附录及各章门禁对齐。按环节勾选；高风险项可下钻到对应 `skills/*/SKILL.md`。

## 意图与需求
- [ ] 目标可观察
- [ ] 边界与非目标清晰
- [ ] 验收标准可判定
- [ ] 关键验收有表格或属性线索（可执行方向）
- [ ] 关键歧义已消除（含正反例或受控表达）
- [ ] 高风险线索已标记
- [ ] 表达低歧义

## 设计与架构
- [ ] 模块职责清晰
- [ ] 关键接口有契约
- [ ] 关键非法状态已尽量不可表示或有显式校验层
- [ ] 高风险路径已识别并标明验证/仿真去向
- [ ] 失败与恢复策略已定义
- [ ] 非确定性依赖边界清晰（便于库级/全系统确定性仿真）
- [ ] 重要决策已记录

## 验证
- [ ] 属性已定义并可追溯到需求（优先可执行形式）
- [ ] 高风险设计已完成相应检查（如模型检查）
- [ ] 实现层关键检查已按目标语言选型并完成
- [ ] 结果可解释且可重复执行
- [ ] 反例/冲突已关闭或已反哺规格

## 实现
- [ ] 代码落在既定边界内
- [ ] 接口行为符合契约
- [ ] 失败路径显式实现
- [ ] 高风险路径保留可检查性（含仿真/Expect 钩子，若需要）
- [ ] 无未批准的架构级偏差
- [ ] 关键逻辑对审阅者可读

## 测试与质量保障
- [ ] 主验收标准有自动测试
- [ ] 关键失败路径有覆盖
- [ ] 关键性质有属性测试或等价可执行规格
- [ ] 高风险输入面有 fuzz 或等价加固（如适用）
- [ ] 关键协作路径有可读行为轨迹（Expect 类）或库级仿真
- [ ] 分布式/恢复关键路径已评估 DST 或等价可复现手段
- [ ] 单元 / 集成 / 必要端到端分层存在
- [ ] 高风险场景有专项用例
- [ ] CI 可执行；失败能指向行为或契约
- [ ] （建议）关键区做过差异或变异抽检
- [ ] 复杂度/静态门禁未无故放松

## 集成与交付
- [ ] 集成后检查通过
- [ ] 关键路径的属性/场景/仿真回归未无故跳过
- [ ] 制品版本化可追溯
- [ ] 发布前检查完成
- [ ] 回滚路径可用
- [ ] 发布过程可审计
- [ ] 变更粒度可审（避免不可审的巨型 Agent PR）

## 持续演进
- [ ] 信号有采集与分级
- [ ] 问题能回流到正确层级
- [ ] 修复附带回归保护（含可重放种子/轨迹，若适用）
- [ ] 资产与行为同步更新
- [ ] 复盘结论可执行（写入规则/Skill/门禁）
- [ ] 变更已经可理解的审阅或等价门禁

## 工具与技能生态
- [ ] 各关键环节有最小自动能力
- [ ] 核心 Skill 可触发
- [ ] CI 与本地调用路径一致
- [ ] 权限最小化
- [ ] 冗余技能已清理
- [ ] 重型验证/全系统仿真有明确启用条件
